# DCF 建模工作流与 Eval 设计

日期：2026-07-28
状态：未来方向，待 M1–M3 跑稳后评估
来源：宁德时代 FCFF DCF 实战；《Agent Harness 学习路线图》金融建模方向

> 本文是未来 Lucas 金融建模能力的详细参考。路线图只保留方向、进入条件和摘要；需要设计 DCF fixture、任务、grader 或报告结构时再加载本文。

以下流程来自一次宁德时代 FCFF DCF 实战。它的用途是补全未来 Lucas 金融建模任务的阶段划分、数据契约和校验点，不代表当前已经决定实现该能力。

## 1. 明确估值口径与输出目标

先固定模型边界，再开始取数：

- 使用 FCFF（企业自由现金流）还是 FCFE（股权自由现金流）。
- 预测期长度，例如 5 年或 10 年。
- 终值使用 Gordon Growth 还是退出倍数。
- 输出企业价值、股权价值、每股价值，还是只输出估值区间。
- 是否需要悲观 / 基准 / 乐观情景及 WACC × 永续增长率敏感性。

参考实战采用 10 年 FCFF、Gordon Growth 终值、三情景和二维敏感性。选择 FCFF 后，后续必须始终使用经营口径利润和 WACC，不能中途混入归母净利润或股权资本成本。

## 2. 建立来源清单与可信度

取数前先建立来源表，记录 `source_id`、来源等级、日期、文件 / URL、用途和原始单位：

| 等级 | 来源 | 用途 |
| --- | --- | --- |
| T1 | 公司年报、季报、交易所公告 | 历史财务、股本、债务、业务事实 |
| T2 | 专业行情或严肃财经数据源 | 估值日股价、利率、Beta 等需交叉核对的数据 |
| T3 | 聚合行情 / 自动摘要 | 仅作交叉验证或定位线索 |

Benchmark 中不应访问实时网页，而应把 T1/T2 输入冻结为 fixture，并保留原始页码、表名和单位。Agent 的每个硬编码历史数字都必须能回指 fixture 中的具体字段。

## 3. 提取并标准化历史数据

至少提取：

- 利润表：收入、营业成本、税金、销售 / 管理 / 研发费用、利润总额、所得税。
- 现金流量表及附注：经营现金流、资本开支、固定资产折旧、使用权资产折旧、无形资产与长期待摊摊销。
- 资产负债表：现金、交易性金融资产、有息债务、租赁负债、少数股东权益、总股本及营运资本项目。

进入模型前统一币种、单位和期间。年报的“千元”、模型的“十亿元”和每股价值的“元”必须显式转换，禁止依赖上下文猜测单位。季度数据需要标记为单季 / 累计，未经说明不得直接年化。

## 4. 重构可持续经营利润

不能机械使用包含投资收益、公允价值变动和其他收益的“营业利润”。参考实战使用经营口径 EBIT：

```text
调整后 EBIT
= 营业收入
- 营业成本
- 税金及附加
- 销售费用
- 管理费用
- 研发费用
```

若 fixture 采用其他 EBIT 定义，必须在任务中冻结口径并给出参考公式。Grader 不只校验最终 EBIT，还要校验组成项与符号。

## 5. 计算再投资和营运资本

```text
D&A
= 固定资产折旧
+ 使用权资产折旧
+ 无形资产摊销
+ 长期待摊费用摊销

Capex
= 购建固定资产、无形资产和其他长期资产支付的现金
```

营运资本要区分历史事实与标准化假设。负营运资本可能代表预收款和供应链融资优势，但不能把单年现金释放永久外推。实战中将 `ΔNWC / 增量收入` 设为独立情景假设，而不是直接照搬最近一年变化额。

## 6. 分离事实、假设和公式

模型数据至少分成三类：

- **事实输入**：来自 fixture 的历史财务、股本和净债务，保留来源定位。
- **建模假设**：收入增速、EBIT 率、D&A 率、Capex 率、税率、WACC、永续增长率和营运资本假设。
- **派生结果**：由公式计算的收入、NOPAT、FCFF、折现因子、终值和每股价值。

Agent 不得把假设描述成公司已披露事实；计算区不得把中间结果硬编码成常量。

## 7. 逐期计算 FCFF 与现值

```text
Revenue_t = Revenue_(t-1) × (1 + Growth_t)
EBIT_t    = Revenue_t × EBIT_Margin_t
NOPAT_t   = EBIT_t × (1 - Tax_Rate_t)
FCFF_t    = NOPAT_t + D&A_t - Capex_t - ΔNWC_t
PV_FCFF_t = FCFF_t / (1 + WACC)^t
```

每一行都应保存结构化中间结果，以便 trace、重算和局部 grader 定位错误。不要让模型在自然语言里心算整条公式链。

## 8. 计算终值与股权价值桥

Gordon Growth 终值：

```text
Terminal_Value = FCFF_n × (1 + g) / (WACC - g)
PV_Terminal     = Terminal_Value / (1 + WACC)^n
Enterprise_Value = Σ PV_FCFF + PV_Terminal
```

从企业价值到股权价值还需要单独桥接：

```text
Equity_Value
= Enterprise_Value
+ Cash_and_Trading_Financial_Assets
- Interest_Bearing_and_Lease_Debt
+ Non_Operating_Investments
- Minority_Interest

Value_Per_Share = Equity_Value / Diluted_Shares
```

只有在经营 EBIT 排除了相关投资收益时，非经营性投资才应单独加回；否则可能重复计算。该口径选择必须进入模型 metadata。

## 9. 运行三情景和敏感性分析

三情景需要同时改变一组内部一致的经营与折现假设，而不是只修改最终估值：

- 悲观：较低收入增速 / 利润率、更高再投资率与 WACC。
- 基准：经营指标逐步向成熟期收敛。
- 乐观：增长、利润率和资本效率更强，但仍需有长期收敛。

敏感性矩阵固定基准经营预测，只改变 WACC 与永续增长率。矩阵中心点必须与基准 DCF 完全一致；这是一条成本低、价值高的确定性校验。

## 10. 输出报告并执行审计

建议最终产物至少包含：

1. `Summary`：估值日、当前价、三情景每股价值和关键驱动。
2. `Historical`：历史事实、单位、口径和来源。
3. `Assumptions`：可编辑的情景假设。
4. `DCF Model`：完整 FCFF、终值和股权价值桥。
5. `Sensitivity`：WACC × 永续增长率矩阵。
6. `Sources & Checks`：来源、公式勾稽、状态和错误定位。

最低审计项：

- 单位和期间转换正确。
- EBIT 等于定义中的组成项之和。
- FCFF 等于 NOPAT + D&A - Capex - ΔNWC。
- 企业价值等于预测期现值加终值现值。
- 股权价值桥无漏项、无重复项。
- 敏感性中心等于基准 DCF。
- `WACC > g`，折现因子单调下降，终值占比不超过任务设定的警戒线。
- 输出中不存在 `#REF!`、`#DIV/0!`、`#VALUE!` 等公式错误。
- 事实输入有来源，主观假设有明确标签。

## 最终结果样例：宁德时代说明性 DCF

> 这是工作流的展示样例，不是 Lucas benchmark 的 gold answer，也不是投资建议。数字依赖 2026-07-28 时点的公开数据和主观假设；正式 eval 必须冻结输入、假设和参考公式。

**数据基础**：宁德时代 2025 年报、2026 年一季报和 2026-07-28 行情快照；模型单位为人民币十亿元，每股价值除外。

**基准假设**：

| 假设 | 数值 / 路径 |
| --- | --- |
| 预测期 | 2026—2035 年 |
| 收入增长 | 22.0% 逐步降至 3.5% |
| EBIT 利润率 | 17.0%，中期约 17.2%，长期降至 16.0% |
| D&A / 收入 | 6.3% 逐步降至 5.5% |
| Capex / 收入 | 9.0% 逐步降至 6.0% |
| ΔNWC / 增量收入 | -5.0% |
| 税率 | 15.0% |
| WACC | 9.0% |
| 永续增长率 | 2.5% |

**结果摘要**：

| 情景 | 每股内在价值 | 相对 390.86 元行情快照 |
| --- | ---: | ---: |
| 悲观 | 255.24 元 | -34.7% |
| 基准 | 445.40 元 | +14.0% |
| 乐观 | 732.88 元 | +87.5% |

基准情景下，企业价值约 1.70 万亿元，股权价值约 2.03 万亿元，终值现值约占企业价值 58.3%。WACC 7.5%—10.5%、永续增长率 1.5%—3.5% 的敏感性区间约为 352.81—649.40 元 / 股，9.0% / 2.5% 中心点与基准结果 445.40 元完全勾稽。

## 对未来 Lucas DCF eval 的直接启示

真实实战表明，最终估值数字不是最难的部分；最容易出错的是口径、单位、符号、跨步骤引用和敏感性链接。因此首个 DCF eval 应优先测量：

1. Agent 能否把来源事实、主观假设和派生结果分开。
2. 能否维持跨步骤数据一致性，不在后续步骤悄悄改变收入、WACC 或股本。
3. 能否把计算交给确定性工具，并保留可重算的中间结果。
4. 数据缺失或解析失败时，能否停止、标记缺口并恢复，而不是补造数字。
5. 校验失败时，能否定位到具体组成项或引用，而不是只重做最终答案。

第一个 fixture 可有意加入一个单位陷阱、一个缺失字段和一个负营运资本公司；grader 分别检查标准化、显式缺口处理和符号一致性。最终分数应以公式链和环境产物为主，文字分析质量为辅。
