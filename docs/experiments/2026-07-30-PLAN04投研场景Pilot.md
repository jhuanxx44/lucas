# PLAN-04 投研场景 Pilot

日期：2026-07-30
Task：`PLAN-04`
Suite：`planner-investment-research-experiment-v1`
Variant：当前 `lucas-single`（Optional Planner）
模型：`deepseek-v4-flash`，temperature=0

## 实验问题

此前 PLAN-01～03 即使具备多文件、多产物和条件行动，Flash 也没有调用 Planner；现有 system
prompt 却明确用“系统调研某个行业、对比多家公司”作为 `update_plan` 的示例。本轮新增一个更贴近
Lucas 投研定位的复杂任务，验证 Optional Planner 是否会在它最熟悉的语境中触发。

PLAN-04 只给目标、完成态和约束，不给步骤：Agent 需要基于三家公司 2026H1 正式报告摘要和同日
估值快照，更新三份公司档案，发布投委会横向报告并更新索引。最终环境需要覆盖增长、盈利、现金
质量、估值、催化和风险，区分披露事实与计算，并把关键数字追溯到具体材料路径。

fixture 内 pytest 做确定性 outcome 判卷；报告文件名和排版不固定，grader 通过语义模式发现唯一
2026H1 报告，并接受公司按行或按列、百分比或倍数等价表达。`allowed_diff` 只允许三份公司档案、
一份 2026H1 电力设备报告和索引发生变化。known-bad 失败、Oracle 通过。

## Pilot 修正

首轮 grader 错误地绑定唯一报告文件名和固定表格方向。Agent 使用合理的
`2026H1 储能逆变器横向比较.md`，却被 safety 和 outcome 同时判错。该 raw grade 作废；修正后不改变
Agent 可见的 instruction、fixture、tools、system prompt、模型或预算，再单独运行正式 trial。

首轮行为仍可用于观察模型波动，因为 grader 和 safety 配置不会进入 Agent prompt。首轮虽因 grader
不对齐而无效，但其环境本身也存在真实失败：公司页和报告没有具体来源路径，索引未修改却在最终
回答中声称已更新。

## Trace 对比

### 首轮：0 Planner

Agent 读取四份正式材料、三份公司页和索引，更新公司页并生成报告。它最后再次读取索引，却没有
执行索引写入，然后直接回答“更新索引”。报告和公司页都只写泛化的“来自半年度报告摘要”，没有
落具体文件路径。

### 正式 trial：首次写入前触发 Planner

Agent 在第 10/18 步调用一次 `update_plan`。此时它已读取四份正式材料、索引和曜川电源旧页，尚未
发生写入。计划包含：

```text
读取另外两份旧档案以保留风险
→ 计算关键指标
→ 更新三份公司档案
→ 撰写横向报告
→ 更新索引
→ 最终总结
```

随后它完成另外两份旧档案读取、三份公司页、横向报告和索引写入。相较 0 Planner 首轮，报告和
索引这两个后段交付物均真实落盘，最终回答也与环境一致。

但计划有两个明显缺口：所有阶段状态均为 `pending`，后续没有再次更新；计划没有纳入“每个关键
数字追溯到具体材料路径”这一成功条件。最终公司页没有任何 source path，报告只引用
`sources/2026H1/` 目录而非三份具体文件，因此当前语义 grader 仍正确判定失败。

## 结论

1. **投研语境提高了触发可能，但仍不稳定。** 对 Agent 可见条件相同的两次 Flash 运行中，Planner
   触发 0/1；temperature=0 不等于 provider 行为完全确定。
2. **这次 Plan 与后段交付完整性正相关，但不能证明因果。** 有 Plan 的 trial 完成了索引，无 Plan
   的 trial 漏索引；样本只有两次，且模型轨迹本身存在波动。
3. **Planner 只覆盖大阶段，不会自动覆盖细粒度成功条件。** “可追溯”没有进入计划，最终成为两轮
   共同失败点。仅统计 plan call 会高估 Planner 价值。
4. **完成声明校验仍然必要。** 0 Planner 首轮再次出现“索引未变但回答声称已更新”；有 Plan trial
   则避免了这一具体错误，但 Planner 不是可靠的环境验证器。
5. **PLAN-04 具备继续实验的价值。** 它比 PLAN-02 更贴近真实投委会研究，能同时暴露 Planner
   路由、财务计算、来源归属、跨文件交付和完成声明问题，暂留 capability suite。
