# 怎样公平比较两个检索算法

检索实验最容易犯的错误，是以为自己只替换了排序公式，实际上同时改变了分词、
候选集或空结果处理。本次实验里，旧 TF-IDF 会用零分文档补足 Top-K，而 BM25
不会；这样即使算法没有找到任何相关内容，TF-IDF 也可能因文件顺序偶然得分。

公平对照的核心是“一次只改变一个变量”：两边使用相同文档、相同查询 token、
相同候选集、相同过滤规则和相同 Top-K，只替换 TF-IDF/BM25 的打分公式。

测试语料规模时，也不能只比较一个 46 篇数据集然后猜测 500 篇的结果。本次做法
是为每条查询保留全部相关文档，再逐步加入随机干扰文档。若规模真是主要原因，
两种算法的差值应该随规模呈稳定趋势；实际没有观察到这种趋势。

多次抽样还有一个统计陷阱：同一条查询的 50 次抽样不是 50 条独立查询。因此先在
每条查询内部求平均，再按查询做 bootstrap 和配对随机化检验。最终置信区间跨过
零，说明当前数据无法排除“二者真实表现相同”这个解释。

这不是证明两个算法永远一样，而是把结论限定在证据覆盖的范围内。若要决定生产
方案，仍需真实知识库、独立真实查询和端到端候选实现；算法名称本身不是证据。
