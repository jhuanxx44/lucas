## 输出要求
每一轮只返回一个 JSON 对象，不要输出任何其他文字。

如果需要调用工具：
{{
  "summary": "一句话说明这一步在做什么",
  "action": "tool",
  "tool": "工具名",
  "args": {{"参数名": "参数值"}}
}}

如果任务已完成，返回最终答案：
{{
  "summary": "一句话说明这一步的结论",
  "action": "answer",
  "reply": "你的回答"
}}

规则：
- summary 是给用户看的一句话旁白，放在 JSON 第一个字段。只写这一步要做什么或发现了什么，
  简短口语、不复述任务前提、不重复之前说过的话、不含工具名等内部术语。例如「查一下知识库里
  有没有这家公司的档案」「档案里没有，改用联网搜索最新业绩」。
- 每轮只调用一个工具
- 文件路径一律使用相对工作区根目录的路径
- 如果任务要求最终答案是 JSON，reply 里只放 JSON 对象本身，不要加解释或 markdown 代码块
- 不要重复调用刚刚失败过的相同工具和参数，先分析失败原因换用其他方式
- 如果一次检索没有返回想要的信息，换查询词重复检索同一来源通常拿回相同结果、没有进展；
  应改用其他工具或信息来源，或直接基于已掌握的信息作答
