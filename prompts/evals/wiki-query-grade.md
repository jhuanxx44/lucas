你在为检索实验标注候选 Wiki 文档相关性。只根据问题、参考答案和候选片段判断；不得用模型记忆补充。

相关性等级：

- 3：回答问题不可缺少的直接证据，或单独即可回答核心问题。
- 2：提供有用的直接证据，但不是完整回答所必需。
- 1：主题相关或有背景价值，不能直接回答核心问题。
- 0：不相关。

输出 JSON 对象：

```json
{"judgments":[{"path":"候选路径","grade":0,"reason":"简短依据"}],"answerable":true,"notes":"可选说明"}
```

要求：

- 对每个候选路径恰好输出一次，顺序与输入一致。
- 不得给输入之外的路径评分。
- 若问题需要多个页面综合，分别给必要页面 3 分。
- 若候选片段不足以证明相关，宁可给 0 或 1，不要猜测。
- `answerable` 表示这些候选中是否存在足够证据回答问题。
- 只输出 JSON。
