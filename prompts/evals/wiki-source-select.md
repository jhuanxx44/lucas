你是评估知识库的来源策展员。下面每项都是从真实 Wikipedia 正文内链发现的页面标题。

允许的领域：半导体、光通信、通信、人工智能、云计算、互联网、汽车、新能源、
消费电子、软件服务、食品饮料、餐饮、体育用品、文化、自然、体育。

候选：

{candidates}

只返回 JSON：

{{
  "items": [
    {{
      "id": 1,
      "keep": true,
      "domain": "允许的领域之一",
      "page_type": "company|industry|concept",
      "reason": "一句话说明保留或拒绝原因"
    }}
  ]
}}

规则：

1. 每个输入 id 必须恰好返回一次，顺序一致。
2. 保留有独立知识价值、能形成高质量页面并适合检索实验的公司、技术、产品、行业、
   重要事件、代表性人物或具体文化/自然/体育主题。
3. 拒绝过于宽泛的国家、省市、一般商业字段、年份、列表、消歧义页、纯导航概念、
   与允许领域都无明确关系的页面。
4. domain 按页面主题本身判断，不照抄 suggested_domain；例如“美国”不能归入半导体。
5. 公司和明确商业组织用 company，行业类别用 industry，其余用 concept。
6. keep=false 时 domain 仍选择最接近领域，便于审计，但不会进入母库。
