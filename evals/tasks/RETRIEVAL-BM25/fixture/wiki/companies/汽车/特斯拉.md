**特斯拉公司**（英语：Tesla, Inc.），旧称 **特斯拉汽车**（英语：Tesla Motors），是 美国 最大的 电动汽车 及 太阳能板 公司，总部设于 德克薩斯州 奧斯汀，与 Panasonic 合作电池业务，产銷电动汽车、车载电脑（FSD系统），太阳能板及儲能 设備 与系统解决方案。特斯拉是世界上最早的 自动駕駛汽车 生产商，至2018年，特斯拉汽车已经成为 世界 最畅销 充电 式汽车公司。

### 创立时期

马丁·艾伯哈德 和 马克·塔彭宁 于2003年7月1日创立公司， 创始人 将公司命名为“特斯拉汽车”（Tesla Motors），以纪念 物理学家 尼古拉·特斯拉。公司成立后不久，工程师萊特（Ian Wright）成为公司的第3号员工。

2004年， 伊隆·马斯克 以A轮投资人的身份加入该公司成为 董事长，并雇用 锂电池 专家史特勞贝爾（英语：J. B. Straubel）任 CTO，组成公司早期团队。2007年8月，时任公司CEO的创始人 马丁·艾伯哈德 宣布辞职，11月，艾伯哈德被逐出 董事会，转由Michael Marks接任临时行政总裁，11月末，泽夫·德罗里（英语：Ze%27ev\_Drori）接任新的行政总裁。另一位创始人 马克·塔彭宁 则先后担任公司的 财务总監、副总裁等职位直到2008年，二位创始人先后离开特斯拉。2008年10月，马斯克成为特斯拉的第四任CEO。

!.jpg) 特斯拉汽车 台北 內湖区 展示中心兼保修厂!.jpg) 位于 台北捷运 圓山站 附近的特斯拉电动车的专属充电站

特斯拉研发的第一辆车是以英国 莲花汽车 Lotus Elise为基礎的纯电动跑车 特斯拉Roadster，该车是首辆使用锂离子电池的汽车，也是第一辆充电能行驶超过200英里的电动汽车。其跑车型号从0加速到60mph只需3.7秒，根据公司的环境测试，能量效率为 Toyota Prius 的两倍。从2008年至2012年，特斯拉在31个国家销售超过2250辆Roadster。从2010年开始，特斯拉为 英国 和 爱尔兰 市场生产驾驶座右置的Roadster，并扩大销售至 澳大利亚、 日本、 香港 和 新加坡。公司从2011年底停止在美国市场销售Roadster。

2009年3月26日，特斯拉为全电动豪华车 Tesla Model S 揭幕，预期基础价格为税前57400美元，引发全世界电动车热潮。2010年5月，特斯拉从丰田公司手中买下 新联合汽车制造公司 的生产工厂，作为北美生产中心。2010年6月29日，特斯拉在 纳斯达克 上市发行股票，成为1956年 福特汽车 公司上市以来，首家上市募股的美国汽车公司。

除纯电动车外，特斯拉也为其他汽车公司的电动车提供电池等的零件。对多顆电池能源管理的技术是Tesla的优势所在。2014年7月，特斯拉和松下合作，在美国建设锂电池工厂（Giga Factory）以满足自己的锂电池需求，并降低锂电池的成本。

2016年2月，特斯拉获得Tesla.com 域名，在此之前此域名由硅谷工程师格羅斯曼（Stu Grossman）于1992年註冊但未曾使用。新域名后来取代了一直在使用的Teslamotors.com。

2025年半导体龍头 三星电子 与特斯拉达成金額高达270亿美元的晶片合作长期协议，创下全世界史上在晶片科技的最大合约。

### 收购

### SolarCity

2016年6月21日，特斯拉宣佈以全股票的方案出价收购全美国最大的 太阳能 公司 SolarCity，收购价为每股26.50至28.50美元，较SolarCity周二的收盤价21.19美元有25%至35%的溢价率，交易总价值为28亿美元。SolarCity的董事长 伊隆·马斯克 表示，收购SolarCity将使特斯拉转型成为“全球唯一垂直整合的能源公司，向客户提供端到端的 清潔能源 产品”，包括太阳能面板、家用儲能设備，以及电动车。SolarCity承认特斯拉的收购提议，并表示将仔細评估特斯拉的收购报价。特斯拉表示，只願在友好的基礎上进行交易。

收购消息公佈后，SolarCity股价盤后大漲15.62%，特斯拉盤后则重挫约12%。该公司2016年6月22日收跌0.04%，报219.61点。特斯拉宣佈以总价最高28.6亿美元收购太阳能公司SolarCity之后，特斯拉公司股价大跌超过10%。对于这兩家大股東都是伊隆·马斯克的兄弟公司之间的收购，外界争议声很大。值得注意的是，特斯拉行政总裁伊隆·马斯克目前是兩家公司的第一大股東，同时兼任董事长。SolarCity联合创始人、行政总裁Lyndon Rive则是伊隆·马斯克的表弟。

伊隆·马斯克本人表示，从现金流的觀点看，SolarCity非常健康，且2016年的现金流将会转正。他同时表示此交易是创建一家清潔能源公司长期计劃（Master Plan）的一部分，未来的特斯拉将会利用必然趨勢，让所有的机车变为电动车，且消费者能夠享用到太阳能。

同年8月1日，Tesla再次声明已达成用26亿美元买下SolarCity的协议，而SolarCity则有45天的猶豫期。双方股東于2016年11月17日投票通过26亿美元的收购方案，为太阳能业史上最龐大的交易，SolarCity正式被纳入成为Tesla旗下的子公司。

### Maxwell

2019年2月4日，特斯拉宣佈以換股方式斥资2.18亿 美元 收购超级电容器制造商Maxwell，其核心技术有干电池电极技术和超级电容驱动的能源储存业务，随后Maxwell将与特斯拉的一家子公司合并，成为特斯拉的全资子公司，不过鋰电池仍然会由 Panasonic 进行制造。2019年5月16日，特斯拉完成对Maxwell的收购，正式接管电池技术。

2020年12月23日，特斯拉行政总裁伊隆·马斯克于 Twitter 透露，以往欲将公司卖盤予 蘋果公司，但未能成功，当时作价僅现价十分之一。

### 更名

2017年2月，特斯拉汽车正式更名为 **特斯拉**（Tesla Inc.），并进一步把业务由电动车拓展到住宅及商业太阳能蓄电系统，成为清潔能源企业，向客户提供端到端的清潔能源产品。[\[来源请求\]]( "Wikipedia:列明来源")

### 加密货币

2021年初，特斯拉斥资15亿美元购买 比特币，成为比特币的主要投资者之一，并于2021年3月24日开始接受比特币作为其在美国销售车辆的支付方式。然而仅仅49天后，因虑及比特币挖矿过程会增加化石燃料消耗，与特斯拉鼓励向可持续能源转型的使命背道而驰，该公司停止接受比特币支付。这一消息宣布后，比特币价格下跌了约12%。截至2022年7月，特斯拉已经以亏本价格出售了大约75%的比特币持仓，声称持有这一加密货币有损公司的盈利能力。

2024年5月4日，特斯拉悄然更新官网，宣布开始接受 狗狗币 作为部分产品的支付方式。虽然目前还不能用狗狗币购买特斯拉整车，但可以支付购买一些特斯拉周边商品。随着新闻媒体开始报道此事，狗狗币的价格飙升，5月2日该代币的价格还不到0.13美元，到5月6日已接近0.17美元。

### 海外发展

#### 中国市场

主条目： 特斯拉上海超级工厂

2014年1月，伊隆·马斯克首次提出在中国兴建汽车生产工厂，2017年6月确认落户于上海 南汇新城镇 工业区。2018年6月5日，在特斯拉股东大会上，特斯拉披露了在中国上海建设美国以外首个工厂的计划。2018年7月10日， 马斯克 和 上海市人民政府 签订协议，宣布特斯拉中国工厂在临港落户。一般被看作是中美之间贸易战的影響而建设，因为中国在特斯拉的銷售量中佔比不低。特斯拉上海超级工厂占地86万平米，总投资额超20亿美金。当地已经在进行整地，2019年1月7日马斯克亲臨进行破土典禮，初期产能2019年底就能投产，规劃在2020年开始将逐步达到25万輛，将全部用来供应大中華市场。
2020年1月7日在工厂交付典礼上，马斯克宣布对外向一般大众消费者交车，并且启动中国制造Model Y项目。2020年10月26日，特斯拉上海超级工厂开始向 欧洲 出口电动汽车。截至2021年1月 (2021-01)[\[update\]]，工厂年产能为25万辆，计划增加至45万辆。同年初，特斯拉宣布开启“Roadrunner”动力电池自产计划。2月， 宁德时代新能源科技股份有限公司 对外宣布与特斯拉签订了量产供货定价协议，5月11日，特斯拉的电池供货商 宁德时代 宣布对特斯拉供货不限于 磷酸铁锂 或者三元电池，将向无钴电池发展。

#### 特斯拉欧洲超级工厂

主条目： 特斯拉欧洲超级工厂

特斯拉欧洲超级工厂于2022年开业，该工厂是继上海之后特斯拉的第二家海外超级工厂，也是在欧洲的第一个制造基地，位于德国 柏林勃蘭登堡机场 附近。

#### 马来西亞市场

2023年初， 马来西亚国际贸易与工业部 宣布，获准特斯拉在该国建立业务。特斯拉是马来西亚 纯电动车 全球领导者计划的首个申请者，获得批准意味着特斯拉将很快在这个东南亚国家建立销售、服务和充电网络。

#### 特斯拉Roadster

主条目： 特斯拉Roadster

特斯拉Roadster是基于 蓮花Elise 的双门双座电动跑车，其理论最大续航里程超过了320km，从2008年面世到2012年停产，一共销售了2250辆左右。Tesla Roadster是全球首款量产版电动敞篷跑车，Roadster的美国最低售价为109,000美元。在英国的最低售价为86,950英镑，在欧洲大陆的最低售价为84,000欧元。身为电动车，Roadster在欧洲也有资格享有政府补贴。

2017年11月，特斯拉发表新款 Roadster "特斯拉Roadster (2020)")，0-60mph加速能力达到1.9秒，最高时速超过400公里，续航力为1,000公里，售价为200,000美金。

#### Tesla Model S

主条目： Tesla Model S

Tesla Model S是一款高性能电动汽车，一开始的代号为"Whitestar"，2008年6月发布于新聞稿，2012年6月开始在美国交车。

Model S的长宽高分别为：4,970x1,963x1,435mm，轴距达到2,960mm。这台电动车（P90D）的电动机可以提供762马力的最大动力，713N·m的峰值扭矩，这让Model S的百公里加速达到2.9秒（Ludicrous），0－400米加速也只需10.9秒。它有三种电池规格供消费者选择，分别可以驱动车辆行驶260公里、370公里和480公里，而配备这三种电池的Model S的售价则分别为57,400美元、67,400美元和77,400美元。Model S在 美国国家公路交通安全管理局 进行的碰撞测试中获得了5.4星的高分，这是NHTSA历史上测试的所有车型中的最高分。该车型2013年全球总销量是2.23万辆。

#### Tesla Model X

主条目： Tesla Model X

Tesla Model X是一款5/6/7座 运动型多用途车，2012年2月发表，2015年9月开始交车。

鷹翼门是此款车的最大特色之一，后側门能以向上延展方式掀开，同时偵測側边及上方的障礙物避免碰撞，达到即便在狹窄的空间范围仍可轻鬆进出。

#### Tesla Model 3

主条目： Tesla Model 3

Tesla Model 3是一款入门电动车，一开始的代号为"BlueStar"，2016年3月31日发布，2017年7月开始量产并交付首批车輛。

初期先交付美国的订单，版本为长续航里程电池版本。

标準电池版本的生产将于2017年11月开始，左駕车款的全球交付将于2018下半年开始，2019年开始生产右駕车款。

#### Tesla Model Y

主条目： Tesla Model Y

Model Y是一款纯电动的中型SUV，可容纳五位或七位成人，车輛配備双马达全轮驅动，并提供最佳的保护。Model Y在2023年第一季度成为全球最畅销车型，共销售267,200辆。这是一个历史的时刻，在汽车行业的发展历史中纯电动汽车首次登上全球销量排行榜榜首。除了Model Y外，前五名的其他四个车型皆为 丰田汽车 的燃油车型。

#### Tesla Semi

主条目：特斯拉Semi（英语：Tesla Semi）

Tesla Semi是一款纯电动半挂车，该款车型于2017年11月首次亮相，Tesla为Semi规划了专用卡车充电桩，并将其命名为Megacharger，2021年，特斯拉在内华达州超级工厂部署了首个Megacharger，特斯拉预计将在美国和欧洲部署超四千枚卡车充电桩。2022年12月，特斯拉在其 内华达州超级工厂 举行交付仪式，向 百事公司 交付了首批Semi电动半挂车，但截至2023年10月，特斯拉只生产了大约70辆Semi卡车，其主要客户是 百事 和 敦豪航空货运公司。Semi的满载整重约为8.2万磅（约合37吨），其满载状况下的续航里程分为300英里（约合482.8公里）与500英里（约合804.7公里）两种版本，空载时Semi的0至60英里/小时（约96.6公里/小时）加速用时为5秒，满载时0至60英里/小时加速用时为20秒。特斯拉为生产Semi建立了特斯拉内华达州Semi工厂，但该工厂尚处于建设中，其负责人表示该工厂有望于2025年投产，特斯拉计划每年生产5万辆Semi卡车。

#### Tesla Cybertruck

主条目： 特斯拉赛博越野旅行车

Cybertruck的车身外殼制造加强堅固度及耐用度，充分保护车上的乘客。由幾乎不可穿透的外殼车架，到30X超硬冷軋不銹钢架外殼，配合Tesla裝甲玻璃，均为極高强度和耐用设计。光滑的单色外殼有助修飾凹痕、損毀的表面及长期使用而自然产生的腐蝕痕跡，整个外殼车架罩着整架车輛，为駕駛者及乘客提供最大保护。超硬玻璃和聚合物层复合材料可以吸收或转移衝击力，提升防撞表现和耐損程度。

除了可用来放置你的工具箱、轮胎和Cyberquad的儲物空间，另外还有備用空间。可供你充份运用的100立方英尺的外部可上鎖儲物空间，包括床底櫃、前行李廂和帆柱。

#### Tesla Cybercab

主条目： 特斯拉Cybercab

Cybercab为特斯拉推出的无人驾驶双座车型，外观为金色金属，车内取消了方向盘和脚踏板，通过Tesla Vision纯视觉自动驾驶和端到端神经网络实现无人驾驶。此外，车辆定位为网约车出行服务，后备箱可支持城市小型客运，并配备无线充电和机械臂自动清洁等功能。

### 能源

#### Tesla Powerwall

Tesla Powerwall是一款由特斯拉汽车研发的锂电池集成家用储能系统，适合储存可再生能源，如太阳能和风能产生的电力，在晚间或无风的时候供应家庭和企业使用。也为电动车辆充电。该产品在2015年公布，预计2017年随特斯拉的 内华达工厂 完工后开始发售。

#### Tesla Solar Roof

Solar Roof是屋頂 太阳能板 来收集太阳能，再将阳光转換成电力，为家居供电。配合Powerwall家用电池使用，能把日间收集的太阳能儲起，在没有阳光时都能享用太阳能。

## 超級充电站

位于北美的超級充电站

特斯拉亦有各种相应充电站设備供车主使用。2019年3月，特斯拉发布了充电峰值可达250kW的第三代超级充电桩V3 Supercharger，Model 3长续航版只需5分鐘即可補充约120公里的行駛里程。

截至2021年2月18日 (2021-02-18)[\[update\]]，特斯拉在全球有超过2564个超級充电站。北美有1101个站，歐洲有592个，亞太地区有498个。

### 中国大陆

自2014年4月特斯拉在中国大陆建设了第1个超级充电站后，特斯拉在中国大陆的超级充电站以年建设50-100座的速度铺开。2022年1月4日，特斯拉宣布位于中国 新疆维吾尔自治区 的首家特斯拉中心乌鲁木齐特斯拉中心开业，特斯拉目前在中国大陆的60个城市设有门店。截至2022年7月 (2022-07)[\[update\]]，特斯拉在中国大陆已建设开放1,200多座超级充电站，700多座目的地充电站，覆盖370多个城市及地区。

### 香港

截至2024年9月 (2024-09)[\[update\]]，香港共设有超过80个超級充电站及超过403个超級充电器。

### 新加坡

受新加坡政府对电动汽车的政策变动影响，2021年2月，特斯拉重返新加坡市场开启网上订车，并于7月19日在新加坡开设了首座超级充电站。

### 台湾

截至2020年3月 (2020-03)[\[update\]]底，台湾有17座超級充电站。同时特斯拉承諾，台湾将是亞洲第一波引入第三代超級充电站的地区之一，其中一座已于2020年6月于 国立台湾大学 啟用。

2021年，特斯拉預计在台湾再设置13座超級充电站，以使其在全岛的充电站总数达到38个，旨在滿足特斯拉车主的充电需求，以供应车主在台湾更长途的旅行。自2020年10月15日起，Tesla车主使用超級充电站的充电费用依据充电的时间和地点，每度以7-12元 新台币 浮动计价。

## 争议与批评

主条目： 特斯拉公司相关争议

多年来，特斯拉公司在 产品安全、 自动驾驶技术、 劳工权益、数据隐私、企业管理及国际政治等领域持续引发争议。随着其在全球电动车市场影响力扩大，特斯拉多次因车辆质量问题、刹车失灵投诉、电池起火事故及大规模 召回 事件受到监管机构和媒体关注，其 Autopilot 与 完全自动驾驶（FSD）系统亦因涉及 交通事故、安全性及宣传方式而长期受到质疑。与此同时，特斯拉在美国及欧洲曾被指存在反工会行为（英语：Tesla and trade unions）、工作环境问题及 种族歧视 争议，并多次面临员工诉讼。公司在中国的发展亦引发广泛讨论，包括获得政府支持建设 特斯拉上海超级工厂、车辆数据收集与储存问题，以及与中国政府关系密切所带来的国家安全和 商业伦理 争议。此外，特斯拉位于新疆 乌鲁木齐 的展厅曾因人权议题受到国际组织和部分美国政界人士批评。作为公司实际控制人与公众形象代表， 埃隆·马斯克 在社交媒体及政治议题上的言论亦多次引发舆论风波，并对特斯拉股价和企业形象造成影响。由于相关事件频繁受到全球媒体报道，特斯拉长期被视为科技产业中最具争议性的企业之一。
