# 英特尔

英特尔

**英特爾**（英语：）是一家总部位于 美国 加利福尼亚州 圣克拉拉 "圣克拉拉 (加利福尼亚州)") 的半 公营事业 上市 半导体 公司，其为世界上 第二大 的半导体公司，也是首家推出 x86 架构 中央处理器（CPU）的公司。英特尔由 罗伯特·诺伊斯、 高登·摩爾、 安迪·葛洛夫，以“ **集成电子**”（）之名在1968年7月18日共同创办公司，将高階晶片设计能力与領导业界的制造能力结合在一起。英特爾也有开发 主机板 芯片组、 网卡、 闪存、 圖形处理器（GPU），与对通讯与运算相关的产品等。“”的广告标语， Pentium 系列处理器以及与 微软 组成的「 Wintel」联盟在1990年代间非常成功地打響英特爾的品牌名号。

英特爾早期在开发 SRAM 与 DRAM 的記憶体晶片，在1990年代之前这些記憶体晶片是英特爾的主要业务。在1990年代时，英特爾做了相当大的投资在新的微处理器设计上与培养快速崛起的 个人电脑（PC）工业。在这段期间英特爾成为PC微处理器的供应領导者，而且市场定位具有相当大的攻勢与有时令人争议的行銷策略，就像是 微软 公司一樣支配着PC工业的发展方向。而发表的2007年在世界上最强大的品牌排名显示出英特爾的品牌价值由第15名掉落了10个名次到第25名。自2010年代以来，英特尔开始在市场上面临越来越激烈的竞争，使其在PC市场的主导地位受到挑战，尽管如此，截止到2023年，英特尔仍在x86芯片市场中维持着68.4%的市场份额。而英特尔能独立设计和制造芯片的能力在半导体行业也被认为是罕见的，因为现今大多数芯片设计企业都不具备 半导体器件制造 能力，是依托 晶圆代工厂 来生产自己设计的芯片的 无厂半导体公司，如英特尔的两个主要竞争对手 AMD 与 英伟达。此外，英特尔亦经营着晶圆代工的业务，但英特尔已于2024年9月宣布会将该业务独立为子公司。

### 创办起源

1955年，「电晶体之父」 威廉·肖克利 離开 贝尔实验室，创建 肖克利半导体实驗室，并吸引许多有才華的年轻科学家加入。但很快，肖克利的管理方法和怪异行为引起员工的不滿。其中，被肖克利称为「 八叛逆」的 罗伯特·诺伊斯 和 高登·摩爾 等八人联合辭职，并于1957年10月共同创办 仙童半导体公司。后来让Intel在1990年代有着决定性地位的匈牙利人 安迪·葛洛夫 是于1963年在高登·摩爾的邀请下加入仙童半导体公司。

由于仙童半导体快速发展，导致內部组织管理与产品问題日益失衡。1968年7月，仙童半导体其中兩位共同创办人罗伯特·诺伊斯、高登·摩爾请辭，并于同年7月16日以“集成电子”（）一名共同创办英特尔公司。安迪·葛洛夫也志願跟隨高登·摩爾的腳步，成为英特爾第3位员工。在 安迪·葛洛夫 的口述自传中表示，如果以「他是英特爾第3位员工」的角度来看，他是「英特爾创办人之一」。但若以 所有权 来说，因未受邀1美元价格购股，所以是首位自願加入的员工。

在剛创立新公司时，高登·摩爾与羅伯特·諾伊斯想要将新公司命名为「摩爾·诺伊斯」（Moore Noyce）。不过这个名称听起来像「」（“更多 雜讯”，一般解作“噪音”），不太適合用于电子公司。于是在决定以的字首组成的“Intel”之前，大约有一年的时间他们使用「NM电子」来做公司名称。不过当时Intel的品牌已经被一家连鎖旅館註冊，所以当时他们就买下Intel商标才成为现今的Intel公司。

### 快速成长

在剛创立的时候，Intel制造半导体的能力在当时而言是相当突出的，而当时他们主要的产品是 SRAM 的晶片。Intel在70年代时因为扩厂与升級制程的关系，能夠主导多种記憶体的生产，因而业务增长。

1971年，Intel制造出第一顆处理器 Intel 4004；1972年制造出第一台 微型计算机，而在80年代初期他们的主要业务还是在 DRAM 晶片。不过，競争力日益提升的 日本 半导体制造商在1983年大大的降低半导体市场的利潤，同时 IBM PC（IBM个人电脑）的成功让Intel的CEO Grove深信要将公司透过开发方向指向处理器，来改变业务模式的基本方向。而在80年代的这十年之中发现这个决定是相当正確的，造成Intel在这10年间空前增长，成为最主要（和最有利可圖）的在PC产业的硬体供应商。

### 成长趨緩

2000年之后，由于高階处理器的需求成长減緩，来自新兴市场的競争者逐漸地获得不小的市场份額，Intel的支配地位因此被削弱。在2000年初时CEO克雷格·贝瑞特（英语：en:Craig Barrett (chief executive) "en:Craig Barrett (chief executive)")）当时决定拓展公司在半导体产业之外的业务，不过最后少部分是成功的。

2005年，CEO保羅·歐德寧要重新把业务重点放在处理器核心与各式平台的晶片组，僱用超过20000名员工将公司改组。不过由于利潤降低，在2006年9月Intel发佈重组计劃，导致在2006年7月有高达10%的员工被解僱，而在劍橋大学的研究实驗室也在2006年底关闭。

2006年6月27日，Intel发佈售出 XScale 的技术。Intel同意以价值6亿美元现金和承担具体的法律责任售出XScale处理器的业务给 邁威爾科技有限公司。这一步是Intel有意要让业务重点更集中于x86核心架构与伺服器业务。而售出案于2006年11月9日完成。

2025年8月22日，美国政府收购英特爾9.9%的股份，成为该公司最大股東。

## 产品历史

### SRAM与微处理器

Intel 4004处理器

Intel第一个主力銷售产品是 移位暫存 記憶体与隨机存取 記憶体 IC，而在70年代时Intel成为这三种競争激烈的 DRAM、 SRAM 与 ROM 市场中的領导厂商。就在此时，英特爾的幾位工程师，分別是Marcian Hoff、Federico Faggin、Stanley Mazor、Masatoshi Shima共同发明第一顆 微处理器 Intel 4004。本来的发展是让日本Busicom公司生产的计算器中替換一些 应用导向积体电路，雖然微处理机直到80年代中期才成为Intel的营业核心，不过Intel 4004在1971年11月15日就在大众市场推出，比記憶体更早。

### 从生产DRAM到处理器

在个人电脑領域在萌芽的1983年时， 日本 的記憶体晶片制造厂日益压縮Intel的利潤，而当时的总裁 安迪·葛洛夫 计画将公司带領发展至微处理器的方向走。葛洛夫在他寫的一书「十倍数时代」（Only the Paranoid Survive）中对这次转型的敘述。他的计劃中一个关鍵因素是觀念，接着是周全的考慮，想要让 8086 微处理器由自己独立生产。

虽然当时礙于积体电路的制程无法让Intel独立生产以应付消费者的需求，但格羅夫还是在三个不同位置的工厂开始生产处理器，并停止授权晶片设计给像是Zilog（英语：en:Zilog）与 AMD 的競争对手。当PC工业位于蓬勃发展的80年代与90年代时，Intel是其中最大的受益者。

### Intel，x86处理器，与IBM PC

儘管在英特爾，处理器是多么的重要， 4004 处理器与后繼的 8008 与 8080 在当时还不是Intel最主要的收入来源。而接下来于1978年设计完成的 8086（以及削弱版的 8088），英特爾展开了一項名为「征服运算」（Operation Crush）的大型市场推广及銷售活动，有意的要儘可能的说服消费者去使用他的处理器。当时的活动导致IBM创立了IBM个人电脑事业部，雖然这一点的重要性在当时并没有充分使用。

而 IBM 在1981年发表他的个人电脑，而且迅速的大受歡迎。而在1982年，Intel推出 80286 微处理器，而这顆处理器在兩年后使用在IBM PC/AT上。而第一家IBM PC相容机制造厂商 Compaq 在1985年推出了搭载 80286 的桌上型电脑，而在1986年也很快的推出搭载 80386 的电脑，在PC相容系统的市场与IBM互相競争，也確立了Intel为最大的重点组件供应者。

而在1975年，公司开始了一項计画去开发一个高度先进的32位元微处理器，最后在1981年时以 Intel iPAX 432 的名称推出。而该计画的要求过高而处理器始終无法滿足其性能指标，所以并没有在市场上取得成功。此时Intel则是扩展x86架构到32位元。

#### 386处理器

!.png) Intel 80386 DX-33处理器

在这段期间 安迪·葛洛夫 大力将公司发展目标改变，结束很多 DRAM 的业务与将公司的资源指向微处理器的业务，不过也许比这件事情更重要的是他决定将独自生产386处理器。在这之前，处理器制造厂是处于未成熟階段，而且由于制造过程的问題而常常降低产量或是停止生产中止提供给使用者。而为了要降低这种衝击，就会迫使很多制造厂制造同款晶片来维持供需平衡。像是8080与8086系列的微处理器就有好幾家工厂共同生产，当时比较有名的制造厂则是 Zilog 与 AMD。葛洛夫决定就不授权386的架构给其他制造厂，而在Intel自家在加州、奧勒岡州、亞历桑纳州等三处不同地方的工厂生产处理器，而让买家相信不会供不应求。而在Compaq Deskpro 386成功確立了386处理器是好的CPU选择，Intel也成功的达成了自身生产处理器的能力。而这樣利潤就能幫助更迅速的发展高性能晶片设计和高性能制造能力，让Intel在1990年代早期能夠位于不被质疑的領导位置。

#### 486、Pentium与Itanium

后期的Intel Pentium III处理器

Intel在1989年发表了 486 处理器，而且1990年时正式完成编组第二组设计团队，由此团队设计P5与P6处理器，而且要加速新型处理器的推出时间，从以往的4年以上改为2年推出。由于当时修法改为数字无法当作註冊商标，P5在1993年以 Pentium 的名称推出。而P6在1995年以 Pentium Pro 的姿态推出，而更进步的 Pentium II 则是在1997年出现。而新的处理器架构是在 加州 的 聖塔克拉拉 与 奧勒岡州 的 希爾斯柏勒 交互推出的。

聖塔克拉拉的设计团队在1993年动手参与x86架构的后繼者，架构代号称为P7。第一次嘗试被中止约一年的时间，但很快的经由与HP的工程师合作繼续开发。而开发成果是在2001年6月推出 IA-64 的64位元架构的 Itanium。但是Itanium执行原先的x86应用程式的性能卻不如預期，而且它也无法有效的与最先AMD提出的64位元x86架构（AMD64，之后被Intel採纳并包裝成EM64T）相互競争。目前，Intel已停止开发与佈署Itanium处理器。

而希爾斯柏勒的团队设计出代号为P68的 Willamette 处理器，并以Pentium 4的名称推出市场，而在后期加入了64位元的延伸集给部分的Pentium 4与 Intel Core 2 处理器。而既有晶片的改造团队则幾乎都是在 以色列 的 海法 开发的。

#### Pentium处理器瑕疵

条目： Pentium FDIV bug

在1994年6月，Intel的工程师在Pentium处理器的浮点运算部分发现一个瑕疵。只要以一个特定的浮点数字进行除法运算，就会在低位元处造成錯误，而这个浮点运算的錯误会造成之后运算数值的误差越来越大。而Intel在未来推出的处理器上修正这个问題，不过之后则是拒絕透露更多有关这个瑕疵的问題。[\[来源请求\]]( "Wikipedia:列明来源")

在1994年10月，林渠堡学院的Thomas Nicely教授发现这个bug之后立刻回报给Intel，但是始終没有得到任何答覆，于是在10月30日将有关这个bug的讯息发佈到网路上。而这则bug的讯息则是很快的在网路上传开而被业界新聞採用发佈。由于很容易让一般的使用者「体驗」到这个bug（只需要开啟计算机程式运算此数字即可「体驗」），而Intel针对此问題的声明稿指出，这是制造过程中出现細微的输入錯误，而这则声明稿不被许多电脑使用者接受。而在1994年的感恩节， 紐约时报 跑新聞的記者John Markoff聚焦在这个錯误上作文章。这时Intel才改变态度而决定召回这批有问題的晶片。这个动作造成Intel在1994年少了5亿美元的年营收。

#### Intel Inside、Intel系统部门与Intel架构实驗室

在这段期间，Intel採用了兩种主要的方式让该公司生产的处理器能夠在市场上广泛接受。第一項是在1990年开始，而且众人皆知的Intel Inside行銷以及「貼标签」运动。这項运动让Intel从一个默默无聞的PC组件供应商搖身成家喻户曉的品牌。而第二項则是在90年代初期建立的Intel系统部门，该部门是在制造个人电脑的 主机板，而且內附CPU及記憶体。不久之后，Intel开始制造已组裝完成的「白牌」系统提供给一些如雨后春筍般出现的小型PC组裝公司。于是在90年代中期的極盛时期，Intel制造了超过15%的个人电脑，躍居于第三大的PC提供者。而Intel为了让小型的PC制造厂能夠与大型的PC制造厂競争，更让小型制造厂加速採用最新的处理器与架构，像是 PCI 汇流排、USB以及其他介面。这樣就能夠让新的处理器加速普及率。[\[来源请求\]]( "Wikipedia:列明来源")

而在90年代，Intel的 架构实驗室（IAL）是很多硬体介面的推手，像是 PCI 汇流排、 USB、 藍芽，以及提供于多处理器伺服器的当代先进架构。IAL在软体方面的努力在早期也有部分成果，但是后来软体的趨勢则是往 微软 的方向走。而Intel与微软之间的競争关系则是可以从IAL的副总裁史提芬·麥基迪与微软的反托拉斯的訴訟中窺知一二。

而另一項让Intel的新款处理器得以迅速普及的是微软的 Windows 作业系统的版本更新，理由是每次更新Windows作业系统就需要更强的处理器来达到最佳体驗。从 Windows 95、 Windows 98、 Windows 2000，直到 Windows XP 甚至是 Windows Vista 都是与当代的硬体技术互相对補。

## 企业事宜

### 領导团队与企业架构

在1968年创立Intel的时候，当时的 CEO 是 羅伯特·諾伊斯，在1975年则由 高登·摩爾 担任CEO的位置。 安迪·葛洛夫 在1979年担任公司 总裁 的位置，而摩爾在1987年坐上 董事长 的位置时，则是辅以CEO称号给葛洛夫。在1997年葛洛夫接替摩爾担任董事长，而贝瑞特则是接任总裁的位置。而歐德寧之前是公司总裁，而且对Intel的设计持续相容于 IBM PC 的重要推手，于是2005年5月18日时贝瑞特将该公司的大权转移到 保羅·歐德寧。而 董事会 推举歐德寧担任CEO的位置，且贝瑞特接替了葛洛夫董事长的位置。而葛洛夫雖然从董事长的位置下台，但Intel还是保留了特別顧问的位置给他。

### 僱员

Intel并不是典型的矽谷企业，它的企业文化并不会像 Google 或是 昇阳 那么的隨性。它內部有相当嚴格的精英，能夠获得豐富的工作酬勞，而且并不会长期看轻內部的僱员。

而这家公司之所以能夠远近馳名，主要得力于它的执行团队。Intel已抵制了走向「局外人」的行政总裁。保羅·歐德寧在Intel度过30年的老公司时担任CEO的角色。他的所有高层幕僚都已经通过多年的考驗。在许多情況下，英特爾公司的高层管理人员已用他们的所有职场生涯奉獻于Intel，这在矽谷是一个非常罕見的事情。

Intel有一条强制退休政策，只要执行长达到65歲时就强制退休，但其中只有一个CEO贝瑞特，是真正在65歲退休。以往的所有CEO的退休年齡都低于65歲；葛洛夫在62歲时退休，而羅伯特·諾伊斯和高登·摩爾都在58歲时退休。而57歲的歐德寧在长期生涯中都在一人之下万人之上的位置，他有可能到65歲而退休的CEO。

公司內没有一个人有专属的办公室，甚至歐德寧也是在工作空间（一个开放式樓层使用各式隔板隔出空间）里工作。採用这种工作空间的设计目的是使僱员们达成平等原则，但是有些新进员工卻難以適应这樣子的改变。在业界中Intel并不是唯一採用此方案的公司， HP 其实也有相似概念的无办公室设计。

Intel也有制程设備在加州以外的地方，如 中国、 以色列、 爱爾蘭、 菲律宾、 哥斯达黎加、 俄羅斯 等地。Intel在美国僱用了比较多来自 科羅拉多、 麻州、 亞利桑那、 新墨西哥、 奧勒岡、 德克薩斯、 華盛頓州 及 猶他 的员工。在奧勒岡的Intel僱用了超过16,000名员工，而这些员工主要来自Hillsboro。而Intel在新墨西哥及亞历桑纳的分部也都超过10,000名员工。

#### 多樣性

Intel有多樣化的员工群体。他们的员工群体是以种族、国籍、性別认同和宗教自由为编群组。在1994年，Intel是最早擁有同性戀、双性戀以及跨性別群组的其中一家公司，而且也有穆斯林员工群，还有猶太员工群，以及以聖经为主的基督教员工群。

在2002年 人权运动 发表了第一份企业平等指数，英特爾得到了100%的评价，而且2003年与2004年的评比也都保持着優良的评价。此外，2005年的Working Mother雜誌评选的100个最好公司中，Intel也名列其中。不过，Intel的工作做法仍有受到批评的时候，最着名的就属其与前僱员Ken Hamidi的訴訟案。

### 财务

Intel的 公司市值 为1534.2亿美元（2007年10月31日时）。他以 INTC 的名称公开的能夠在 那斯达克 上交易，而且也是下列股汇市指数的成员： 道瓊工业指数、 S&P 500、 NASDAQ-100、 费城半导体 及 GSTI Software Index。

INTC 是一个被广泛持有的股票，幾乎58.5亿。机构投资者和共同基金持有60%的股权，而公司內部人，包括高登·摩爾和安迪·葛洛夫，持有股份约只3%。Intel在目前的上市历史中，最高收盤价是在2000年8月31日的74.87美元，而到2002年9月23日时的最低收盤价为14.62美元，而在 2007年10月 底，股价则是在25.50至26.50元波动。

#### Intel Inside

1990年4月至2005年

「內有英特爾（中国大陆）/Intel Inside（港澳）/Intel Inside（台湾）」

1989年4月，技术助理-丹尼斯·李·卡特认为英特爾的微处理器 80386 无法取代 80286，主因是終端消费者不会想要80386所提供的强大运算能力，卡特认为必須直接说服80386微处理器才是終端消费者所需要的产品，之后在葛洛夫的支持下，卡特在 丹佛市 报纸广告登上将286黑体字画上紅色「X」，报纸下一版面即出现386并引用文字说明它的優点，此广告隨后在全美报纸刊登，并带动80386銷售量。

卡特认为:「我们希望处理器在电脑中佔有更显眼的位置，她極为重要卻看不見，人们不知道微处理器的存在，它们不认识我们。」「英特爾需要一个品牌，品牌名称不会是386或是486，数字不能登記为商标。」，卡特主张针对終端消费者提出完整行銷计画-「Intel Inside」，他希望打大众广告也和电脑品牌合推广告，也是就是说电脑商如果广告中包含「Intel Inside」以及其生产的电脑中也貼有「Intel Inside」貼纸，英特爾願意分攤广告成本。另外当广告和电脑出现英特爾的品牌可能会造成资讯混亂，沖淡自身品牌价值，所以在「Intel Inside」中的Intel寫的樣式和公司正式商标不同。此计画于1990年4月展开，最先在美国、歐洲及日本发起「Intel Inside」计画和「The Computer Inside」计画。英特爾推出486处理器后，即在中国大陆及港澳地区使用「Intel Inside」和「The Computer Inside」宣传语。隨后应Pentium处理器的推出，Intel在中国大陆及港澳地区推出「给电脑一顆奔馳的芯」宣传语，2003年Intel微调「Intel Inside」Logo，直到2005年5月，歐特尼担任执行长调整组织架构及推动配套行銷再造工程为止。

## 競争对手

在1980年代时，英特爾在全球是前十大的半导体銷售的业者（1987年是第10名），而在1991年以后，英特爾达到了第一名的位置之后就没有再变动了。而其次的半导体公司包括 AMD、 三星、 德州儀器、 東芝 与 意法半导体。

在个人电脑晶片组方面的競争对手包括 威盛电子、 矽统科技、 AMD 与 NVIDIA。而在网路方面的競争对手有 飞思卡爾、 英飞凌、 博通、 Marvell 与 AMCC、 台湾积体电路公司，而Intel在快閃記憶体的競争者则是 飞索、 三星、 奇夢达、 東芝、 意法半导体 与 海力士。

而唯一在 x86 处理器市场中能夠与Intel相抗衡的是 AMD，在1976年的时候AMD与Intel有完整的交叉授权协议：双方能夠在一定时间后使用对方的 专利 技术而不用遭受起訴。但如果有其中一方破产或是被併吞，此交叉授权协议就会自动取消。而像 VIA 或 全美达 这种比较小的競争对手就生产应用于小型电脑或是可攜式组件的低耗能处理器。2010年第二季全球 个人电脑 中央处理器 市场佔有率，Intel以80.7%位列第一，第二是 AMD 佔19.0%， VIA 则佔0.3%。

### 訴訟官司

在2005年9月，英特爾向法院提交了针对 AMD的訴訟（英），反駁AMD的指控，并声明其商业行为是公平和合法的。在这次的反駁，Intel展开了合法辯护的基礎，像是解析AMD侵略性的策略以及指出AMD如今的市场定位，是由于拙劣的商业决策以及管理上的无能，包括制造业的基本能力，以及过分依赖承办的晶片厂所导致的。

法律专家預測这场官司因为Intel的回应指出它们不太可能设法去清算AMD，而且很有可能会打好幾年。

在2006年10月，全美达提出了Intel侵害在电脑架构以及节能技术的专利訴訟。而在2007年10月，全美达与英特爾的訴訟案已经宣告終结，对Intel判处第一年1.5亿美元以及之后5年共2000万美元的罰金。这兩家公司同意放棄起訴对方，而Intel已获得一項永久的非专属授权，能夠在10年內使用当前和今后全美达的专利技术在Intel晶片里面。

### 監管机构的反競争指控

而在2007年7月， 歐盟委员会 正式指控Intel多数针对主要競争对手AMD的反競争行为。这項指控可以溯及2003年时，包括给予優惠的价格给电脑厂商，厂商获得的大多数或全部来自英特爾的CPU，同时电脑制造商就延迟或取消推出採用AMD晶片的产品，并提供低于成本的CPU晶片给政府和教育机构。英特爾根据这項指控回应时表示，这些指控既毫无根据也很无稽，是为了对消费者释出善意才会出现其市场行为。而律师Bruce Sewell也回应说，委员会误解了一些关于价格和制造成本事实的假设。-56)

在2008年2月，公司发言人宣佈，Intel在慕尼黑的办公室已被歐盟競争監管机构为调查其经营手法而被「搜查」。Intel也报告说，他正在配合调查。如果他们找到扼殺競争的证据，英特爾最高会被罰款其年度收入的10%。而Intel的競争对手AMD隨后也会针对这些指控推出一个网站。

在2007年9月， 南韓 監管机构正式指控英特爾违反 反托拉斯法。该调查始于2006年2月，南韓官员突击檢查Intel的韓国办事处。如果罪名成立，该公司有可能被罰款高达年銷售額的3%。

2023年9月22日，欧盟宣布对英特尔滥用市场地位、操控x86核心处理器产品罚款3.7636亿欧元，理由包括英特尔付款给惠普、宏碁、联想等电脑商，以延缓对手产品的上市。

### 收购NVIDIA的传聞

2009年12月，据国外媒体报导，自7月 AMD 收购 ATI 的交易公佈以来，就一直有传聞称英特爾将做出回应，收购ATI的主要競争对手 NVIDIA。

按照股价计算，NVIDIA的市值已经超过100亿美元，英特爾发言人拒絕就此发表评论，称该公司不会就市场传聞发表评论。另一方面，通过收购ATI，AMD进入了一个新市场——圖形芯片市场。但对于英特爾而言，收购NVIDIA无法带来同樣的效果，因为该公司早已开始生产圖形芯片。此外，NVIDIA首席执行长 黄仁勳 目前还不太可能交出公司控制权。Pacific Growth Equities分析师塞特亞·西拉拉（Satya Chillara）表示：「从各个方面来看，这一交易都存在太多变数。」

消息人士称，Intel正在与NVIDIA探討进一步合作。除了技术授权之外，Intel甚至有可能收购NVIDIA。

消息人士称，如果Intel收购NVIDIA，那么NVIDIA CEO黄仁勳可能会担任Intel CEO。

由于投资者对公司在移动领域的表现感到不滿，Intel董事会有史以来第一次考慮从外部选拔CEO。交接将在2013年5月完成，屆时现任CEO保羅·歐德寧（Paul Otellini）将退休。繼歐德寧后，Intel董事会正考慮从外部选拔CEO，黄仁勳会成为这一人选吗？消息人士暗示，Intel的这一举动可能与它在移动业务方面欠缺实力有关。Intel若要收购NVIDIA，不僅会收购其移动处理器部门，也会将 GeForce 显示卡业务一併收购。由于证券市场的保密规定限制，兩家公司都不能透露任何信息。此前，IntelSandy Bridge和Ivy Bridge处理器将採用GeForce显示卡晶片的传言流出后，NVIDIA予以了否认。

## 争议

### Core 2 Duo的广告争议

在2007年，Intel发表了一份 纸本的广告，其广告內容为一个办公室內有6位非洲裔美国选手同时相向起跑，而站在他们之间为一位白人男性。这则广告很容易引起黑人向白人鞠躬下跪的联想，而被指出为种族歧视。不久Intel整合行銷副总南希·巴格特就此对外发佈声明，指出这篇广告是「冷漠且有汙辱性质」。而这股风波则是在幾位英特爾主管在网站上作公开道歉而快速的平息。

### 供应商来源争议

2021年12月，英特尔被发现在其一份向供应商写的信当中提到，其投资者和客户询问该公司是否从中国新疆采购产品或服务，同时多个国家和地区的政府已限制来自新疆的产品，因此该公司需要确保其供应链不使用任何来自新疆的产品及服务。该信件被披露后，其官方微博下涌现大量辱骂英特尔的评论。英特尔酷睿代言人 王俊凯 也于12月22日宣布解除与英特尔的合作关系。

针对供应链问题，英特尔于12月23日发表声明回应称，信件中关于新疆的描述这是出于表示確保遵守美国法律的初衷，并对信件在中国合作伙伴引起的疑问和顾虑表示遗憾，向中国客户、供应商和公众道歉。另外， 中华人民共和国外交部 也对此事做了表态。2022年1月10日，《 华尔街日报》记者查询英特尔官网，发现供应商信件已经更新，其中“不使用任何来自新疆的产品及服务”之类的字句被删除。

### 处理器召回争议

2024年7月，英特爾表示其推出的13、14代处理器因处理器 微码 发生特定算法錯误，进而过度提高 处理器 工作电压，导致处理器出现不穩定现象，更使处理器发生燒毀。英特爾表示預定于2024年8月释出修复更新，但也同时表示此类更新无法修复受影響之产品，并声明不会召回相关受影響之产品，引起受害者不滿。儘管英特爾已针对受影響处理器延长2年保固，但仍无法抑制消费者的怒火，美国律师事务所Abington Cole + Ellery发起对英特爾有关的 集体訴訟。

### 被中国网络空间安全协会点名

2024年10月16日， 中国网络空间安全协会 发布文章《漏洞频发、故障率高，应系统排查英特尔产品网络安全风险》，文章指出英特尔的安全漏洞问题频发，亦批评产品可靠性差，建议对英特尔产品启动 网络安全审查。翌日，英特尔中国表示“将与相关部门保持沟通，澄清相关疑问”，强调坚定承诺其产品安全和质量。

- 430系列－是 Intel 早期的 晶片组，该晶片组支援 Socket 7 的 奔騰MMX 处理器，支援 PCI 和 ISA 插槽。
- 440系列－其中440BX是 Pentium II 时期的经典之作。
- 810系列－这是 Intel 第一款款採用集成显示卡的晶片组。不支援 AGP，使得不能使用AGP显示卡。
- 815系列－搭配 Pentium III 处理器，其中的815EPT正式支持 Tualatin 核心的处理器。
- 850系列－早期的850是为了配合 Pentium 4 的倉促上市而设计的，採用不成熟的 Socket 423 插座并搭配昂貴的 RDRAM 內存使得它与Socket423的 Pentium 4 同时被淘汰出局。新的850E后来作为工作站級別的晶片组上市。
- 845系列－为了摒棄昂貴的 RDRAM 記憶体而设计的搭配 SDRAM 記憶体的晶片组。隨着 DDR 記憶体的上市，英特爾又推出了845D以及后续的845E、845G等晶片组。
- 848／865／875系列－为全面支持含 Hyper-Threading 技术的 Pentium 4 处理器而设计的晶片组，首度支持 双通道記憶体技术（848P为865系列的簡化版本，去掉了对 双通道記憶体技术 的支持）、 SATA 硬碟、 AGP 8X和 USB 2.0等新技术。
- 910／915／925系列－过渡产品，配合採用 LGA 775 封裝的处理器，支援最新的 PCI Express 与 DDR 2 內存，而915系列则保留了对Socket 478、AGP以及DDR內存的支援。只有925系列支持 Pentium 4 Extreme Edition 处理器。
- 945／946／955系列－在原915／925晶片组的基礎上，增加了对 Pentium D 双核心 CPU 的支持。其中955和975系列支持了 Pentium Extreme Edition 处理器。945GT Express晶片组更是支持了 Core Duo 处理器。使用VRM11的975系列主板更支援 Intel Core 2 系列处理器。
- 963／965／975系列－加入对 Core 2 系列处理器的支援，另加入原生的双通道 DDR 2 800MHz的支援。採用新的命名方法，将标识英文字母前置。
- x3x（31／33／35／38）系列－于965系列的基礎上加入1333MHz外頻的支援，并于P35／X38等高階晶片组中加入 DDR3 支援。採用新的命名方法，以第一个英文字母代表类型（如P35是独立晶片组、G35是內建显示功能的晶片组），及最尾的数字代表級別（如G35、G33、G31中以G35最高階）
- x4x（41／43／45／48）系列－x3x系列的改良版，将外頻提升到1600MHz，并支援最新的 PCI Express 2.0。
- x5x（55／57／58）系列－支援 LGA 1366 与 LGA 1156 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7 的晶片组，高端型号採用 QPI 与处理器连接，中低端型号採用 DMI 与处理器连接，不设記憶体控制器—— 北橋，改为內建于处理器中。
- x6x／C20x（61／65／67／68／202／204／206）系列－支援 LGA 1155 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7 的晶片组。
- x7x／C216（75／77／79／216）系列－支援 LGA 2011 与 LGA 1155 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7 的晶片组。Z77/H77/Z75/C216是x6x及C20x系列的改良版，支援 SATA 3.0、 USB 3.0。
- x8x／C22x（81／85／87／222／224／226）系列－支援 LGA 1150 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7 的晶片组。優化了多項硬碟传输性能。
- x9x／C612（97／99／612）系列－支持 LGA 2011 为 LGA 1150 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7 的晶片组。Z97/H97是x8x系列的改良版。全系列增加对 M.2 接口的支持。X99与C612是第一个支持DDR4記憶体的晶片组。
- x1x0／C23x（110/150/170/232/236）系列－支持 LGA 1151 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7 的晶片组。全系列增加对 SATA Express 接口以及 DDR4 記憶体的支持。優化了PCIe存儲性能。
- x2x0／C422（250/270/299/422）系列－支持 LGA 2066 为 LGA 1151 封裝的处理器 Celeron／ Pentium／/ Core i3／ i5／ i7／ i9 的晶片组。Z270/H270/Q270/Q250/B250是x1x0系列的改良版。全系列增加对 Intel Optane 固态硬碟的支持。
- x3x0／C24x（310/360/370/390/242/246）系列－支持 LGA 1151 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7／ i9 的晶片组。由于 Coffee Lake-S CPU可能会在高端Z270主板上燒掉，因为某些针腳的（供电）压力太大。所以Intel增加此改良版，并只支持Coffee Lake-S系列CPU，且不可向下或向上相容。
- x4x0（410/460/470/480/490）系列－支持 LGA 1200 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7／ i9 的晶片组。
- x5x0／C25x（510/560/570/580/590/252/256）系列－支持 LGA 1200 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7／ i9 的晶片组，全系列增加对PCI EXPRESS 4.0的支持。
- x6x0（610/660/670/680/690）系列－支持 LGA 1700 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7／ i9 的晶片组，全系列增加对PCI EXPRESS 5.0以及 DDR5 SDRAM 的支持。
- x7x0／C26x（710/760/770/790/262/266）系列－支持 LGA 1700 封裝的处理器 Celeron／ Pentium／ Core i3／ i5／ i7／ i9 的晶片组，全系列不再支持 Intel Optane。
