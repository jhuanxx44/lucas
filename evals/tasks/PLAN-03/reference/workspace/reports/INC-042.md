# INC-042 支付链路事故报告

## 时间线

- 09:40 payment-provider 路由迁移，上游延迟预算放宽。
- 10:05 checkout 支付超时率达到 11.2%，上游 p95 为 4.8 秒，事故告警触发。

## 证据与根因

- `evidence/metrics-2026-07-30.md`：支付上游响应已超过客户端 2 秒 timeout，库存错误率正常。
- `evidence/deploy-timeline.md`：上游延迟预算变化后 checkout 客户端仍使用旧 timeout。
- `logs/checkout-api.log`：请求在 2 秒后超时。
- `logs/order-worker.log`：出现 `duplicate charge suppressed=false`。

根因是上游延迟预算与 checkout 客户端 timeout 不一致，重试同时放大请求；订单 worker 未强制幂等键。

## 配置变更

- checkout-api：`payment_client.timeout_seconds` 2 → 6，`max_retries` 3 → 1。
- order-worker：`idempotency_key_required` false → true。
- inventory-api 指标正常，保持不变。

## 验证

- `verify checkout-payment --window 10m`
- `verify payment-idempotency --samples 200`

2. checkout-api
