# 存储器

（重定向自 存储器）

**存储器**（英语：memory，台湾译 **记忆体**）是 计算机 中能接收和存储数据，并能根据控制命令提供所存数据的基本硬件。现代的计算机系统以存储器为中心，故存储器的特性是影响整个计算机系统最大吞吐量的决定性因素。

存储器又分为 **主存储器**（main memory，简称“主存”、“内存”，又称“内存储器”）和 **辅助存储器**（auxiliary memory，简称“存储”、“辅存”、“外存”，又称“外存储器”）。主存储器与 中央处理器（CPU）一起构成主机，用来存放计算机运行时随时需要使用的程序和数据，一切数据要被CPU操作都必须先装入主存。主存的工作速度较快，存储容量较小，主要采用半导体存储器。目前大部分计算机系统的主存储器主体为 动态随机存储器（DRAM），“主存储器”乃至“存储器”一词有时特指DRAM；另外， 静态随机存储器（SRAM）与 只读存储器（ROM）等也可作主存储器的一部分。辅助存储器和输入输出设备都属于外设，用来存放CPU运行时暂时不用的各种程序和数据，一般在断电后仍能保存。辅助存储器的存储容量大，工作速度慢，例子如 硬盘、 U盘、 光盘、 磁带 等。

除了可分为主存储器和辅助存储器外，存储器还可按存储介质分为 半导体存储器、 磁表面存储器、 磁芯存储器 和 光盘存储器 等，按存取方式分为随机存储器、只读存储器、 串行访问存储器 等。

传统上，一部电脑最重要的元件是 中央处理器（CPU），因为他负责处理资料，进行所有计算，并且控制电脑內其他所有元件。中央处理器包含兩个部分: 控制单元 以及 算术邏輯单元（ALU）。前者控制资料在中央处理器及記憶体之间的流动。后者处理资料的邏輯运算。如果没有足夠的記憶体，电脑将只能进行固定的工作而且立刻将结果输出。这在 计算机 及 数位讯号处理 是可接受的。 冯·诺伊曼结构 机器擁有足夠的記憶体去儲存正在执行的 指令集 以及资料。结果使电脑不用为了执行一个新的程式而改变硬体的配置，使 程式设计 变得簡单，大部分的电脑都是范紐曼型架构。

所有的記憶体都可以用其核心的特性以及可以用測量而得知的效能，容量来区分。核心的特性有揮发性，读寫性，存取法，以及定址法。測量得知的特性有效能跟容量。

### 容量

主条目： 字节

电脑 使用 二进制 来处理 数据。文件，数字，圖形，影音，或是其他资料都可以用一串 位元 来表示，每一个位元的值不是一就是零。最常見的儲存单位是 位元组，一位元组等于八位元。一份资料可以被任何具有足夠容量去容纳该资料大小的电脑所处理。

根据 电气电子工程师协会（IEEE 1541）和 歐洲联盟（HD 60027-2:2003-03）的标準， 二进制乘数词头 的縮寫为「Ki」、「Mi」、「Gi」，以避免与 国际单位制 混淆。但二进制乘数词头没有广泛被制造业和个人採用，标示为4GB的內存实际上已经是4GiB，但标示为4.7GB的 DVD 实际上是4.37GiB。

对于32位元的作业系统，最多可使用232个地址，即是4GiB。 物理地址扩展 可以让处理器在32位元作业系统存取超过4GiB記憶体，发展64位元处理器则是根本的解决方法，但 作业系统、 驅动程式 和 应用程式 都会有 相容性 问題。

### 揮发性

非揮发性記憶体资料在电源不供电的狀态下仍能保存。这適用于須长期使用的资料。揮发性記憶体资料需要有持续不断的电力才能保持。目前存取速度最快的記憶体是属于揮发性的。因为第一級記憶体需要極快的速度，所以採用揮发性記憶体。
动态隨机存取記憶体（DRAM）一种揮发性記憶体，资料需要每隔一段时间就重新读取或重新寫入，否则资料将会消失。

更多信息： eDRAM、 SDRAM、 SGRAM、 DDR SDRAM、 GDDR、 LPDDR、 QDRSRAM、 EDO DRAM、 XDR DRAM、 RDRAM 和 HBM

靜态隨机存取記憶体（SRAM）一种类似DRAM的記憶体。不同的是在电力持续供应的狀态下，它不用被重新寫入或是读取资料（如果没有电力来支持，资料还是会消失）。

### 读寫性

可读寫的記憶体它允许资料在任一时间被覆寫。如果一台电脑的第一級記憶体不是可读寫的，那这台电脑将无法执行各种任务（至少要有一定数量的第一級記憶体是可读寫的）。而第二級記憶体也有许多是可读寫的。唯读記憶体記憶体內的资料通常不会变，但有时允许资料寫入（Write once read many）这种記憶体也被叫做 **不可变記憶体**，主要備用在第三級跟離线記憶体上， 例如 CD-ROM 以及 CD-R。快速读取低速寫入記憶体例如 CD-RW 和 快閃記憶体。

### 存取法

隨机存取在任何的时间，任何的位置都可以被存取。这適合第一級与第二級記憶体。循序存取要存取的资讯依照順序来存取，一个接着一个; 存取时间长短取决于哪一項资料是最后存取的，这是離线記憶体的特徵。

### 定址法

区块定址根据記憶体区块的 物理地址 来存取资料。在今日的电脑，区块定址通常只出现在第一級記憶体，由电脑程式来存取，而且存取的效率很高，不过对人而言这是个负担。檔案定址资料被分割成 檔案，檔案依照 人类可读的 名称或檔案名称而被选择，其实这也是一种区块定址，不过 作业系统 会将檔案 抽象化，从而让工作更容易被理解。在今日的电脑，第二級，第三級，離线記憶体採用这种方法来定址。內容定址资料依据本身的內容被存取。內容定址被使用于 软体 或 硬体，这让硬体变得有效率，但也变得比较昂貴。硬体內容定址記憶体通常被用于 CPU快取。

### 效能

迟滯时间 "延迟 (工程学)")存取儲存器內部特定区域资料所花的时间。在第一級記憶体中，以奈秒作为合理的 计量单位，第二級記憶体以 毫秒 作为计量单位，以秒作为第三級記憶体的计量单位或是。迟滯时间可以合理的分为读取的迟滯时间和寫入的迟滯时间，以循序存取儲存器来说，有最短、最长与平均迟滯时间。吞吐量将资料读取到或是寫出記憶体的速度。吞吐量通常表示为百万位元组/秒或是MB/s， 位元率 也被使用着。就跟 迟滯时间 "延迟 (工程学)") 一樣，读和寫的速度算做兩筆不同资料。存取资料的速度取决于最大吞吐量。粒度能以单独一个单位被有效率的存取的最大片资料的大小, 例如, 没有引发更多的迟滯时间。可靠度在不同的条件下，非自发性的位元值改变, 或整体 故障率。

## 分类

直至2008年，最常用的数据儲存技术是 半导体、 磁性、 光学，同时还看到一些使用 纸张 作儲存。也有一些曾于过去使用或是在将来会使用的数据儲存技术。市场上存在多种不同形态、不同材质的存储器。到目前为止，任何一种儲存裝置都有其缺点，因此一台电脑通常都有好幾种不同种类的儲存裝置，每一种都有其特別的功能。

电脑記憶体可以根据儲存能力与电源的关系可以分为以下兩类：

### 揮发性記憶体

主条目： 揮发性記憶体

揮发性記憶体（Volatile memory）是指当电源供应中断后，記憶体所儲存的资料便会消失的記憶体。主要有以下的类型：

- 隨机存取記憶体
- 动态隨机存取記憶体，英文缩写写作DRAM，一般每个单元由一个晶体管和一个电容组成（后者在集成电路上可以用两个晶体管模拟）。特点是单元占用资源和空间小，速度比SRAM慢，需要刷新。一般计算机 主記憶体 即由DRAM组成。在PC上，DRAM以内存条的方式出现，DRAM颗粒多为4位或8位位宽，而载有多个颗粒的单根内存条的位宽为64位。
- 靜态隨机存取存儲器，英文缩写写作SRAM，一般每个单元由6个晶体管组成，但近来也出现由8个晶体管构成的SRAM单元。特点是速度快，但单元占用资源比DRAM多。一般 CPU 的 CPU缓存 即由SRAM构成。

### 非揮发性記憶体

主条目： 非揮发性記憶体

非揮发性記憶体（Non-volatile memory）是指即使电源供应中断，記憶体所儲存的资料并不会消失，重新供电后，就能夠读取記憶体中的资料。
主要种类如下：

- 唯读記憶体（ROM）

- 可规化式唯读記憶体（PROM）
- 可擦除可规劃式唯读記憶体（EPROM）
- 电子抹除式可复寫唯读記憶体（EEPROM）
- Flash ROM
- 磁儲存
- 硬碟
- 软碟
- 磁带
- 3D XPoint
- 固态硬碟
- 光儲存
- 光碟

## 記憶体階层

主条目： 記憶体階层

实际上，幾乎所有电脑都有各种不同的記憶体，这些記憶体在中央处理器旁边，构筑成 記憶体階层，在效率和花费兩者之间的拉鋸中，在階层中较低层的記憶体， 頻寬 较低，而且资料到中央处理器的时间也较久， 迟滯时间 "延迟 (工程学)") 较长。传统上分第一級，第二級，第三級，離线記憶体。

### 第一級記憶体

第一級記憶体（又称 主記憶体 或內部記憶体），通常簡称为記憶体，这层的記憶体与中央处理器直接连通，中央处理器会不断读取儲存在这里的指令集，并在需要时执行这些指令集。

历史上， 早期的电脑 使用 延迟线， 威廉士管 作为主要的儲存器。在1954年， 磁芯記憶体 被开发出来大幅取代了上述不太穩定的方法。磁芯記憶体维持優勢至1970年代，此时 积体电路 技术的进步，使得 半导体記憶体 在价格上变得便宜而有競争力。

这使得现代化的 隨机存取記憶体（RAM）被制造出来。该款記憶体的重量轻，尺寸小，然而十分昂貴。这种記憶体被用来做成第一級記憶体，同时它也是 揮发性記憶体，意思就是当电力不再供应时，記憶体內的资料就会消失。

如同右圖所示，在第一級記憶体的內部除了主記憶体，也就是隨机存取記憶体外，还分有兩个或兩个以上的子层:

- 暫存器 被设置在处理器內。每个暫存器都儲存资料中的一个 字 "字 (计算机)")（一个字的大小通常是32位元或64位元）。中央处理器內的指令能让 算术邏輯单元 去执行各种计算或是处理资料。暫存器传输资料的速度是所有記憶体中最快的。
- CPU快取，它传输资料的速度僅次于暫存器。被用来作为提升电脑的效能。大部分经常被使用的资料，会复制另一份存在快取記憶体內，这樣可提升速度，否则速度将会大幅降低，且暫存器也容纳不下那么多资料。多层 快取階层 亦经常被使用—第一层快取容量最小，速度最快且位于处理器內部；第二层快取容量较大且较慢。

主記憶体藉記憶体汇流排与中央处理器连接。有兩种不同的汇流排： 位址汇流排 以及 资料汇流排。一开始中央处理器藉位置汇流排传送数字，这数字就是 記憶体位置，其指出资料的位置。然后中央处理器用资料汇流排将资料读出或寫入。此外， 內存管理单元（MMU）是一种介于中央处理器跟主記憶体的裝置，用来重新计算記憶体位置，例如提供 虛擬地址。

由于RAM具有揮发性，这樣的话电脑就无法儲存开机时需要的指令，因此， 非揮发性記憶体 儲存了执行开机的程式（ BIOS），为了读取较大的程式，先自第二层的非揮发性記憶体读取到隨机存取記憶体，然后执行程式。一种記憶体因着这目的被制出，就是 唯读記憶体（唯读記憶体也是属于隨机存取）。

许多唯读記憶体并不僅僅只能读取，雖然速度慢，但资料还是可以抹除并重新寫入。一些 嵌入式系统 直接使用唯读記憶体来跑程式，因为程式幾乎不会变化，现在的电脑将资料存于第二层非揮发性的記憶体，而非唯读記憶体，这是比较经济的做法。

### 第二級記憶体

去除保护殼之后的 硬碟

第二級記憶体，又称外部記憶体或辅助記憶体，和第一級記憶体不同的是，第二級記憶体和中央处理器并没有直接连通，电脑经常使用記憶体的 I/O 通道来与之连接，第二級記憶体使用 资料緩衝器 来将资料传送至第一級記憶体。在不供应电源的情況下，第二級記憶体的资料仍然不会消失—这表示它是非揮发性的。

现今的电脑， 硬碟 被广泛地做为第二层記憶体，硬碟存取资料的时间大约是幾千分之一秒，或是幾个毫秒。然而，隨机存取記憶体存取资料的时间僅有幾十亿分之一秒，或是幾个奈秒。硬碟的速度只有記憶体存取速度的百万分之一， 光碟，例如 CD 和 DVD，有更长的存取时间。

当资料儲存于碟片时，将资料传送到区块可降低迟滯时间，提升效率，这樣的话需要 外部記憶体演算法。连续存取和区块存取的速度比隨机存取要快得多，所以许多尖端的記憶体都在开发更有效率的演算法来执行连续存取或区块存取。一个突破I/O瓶頸的方法是使用多重磁碟，可以增加第一級与第二級記憶体之间的頻寬。

这里列举一些第二級記憶体的例子： 快閃記憶体（例如 隨身碟 和 固态硬碟）、 软碟、 磁带、 纸带、 打孔卡、 RAM disk、 Zip Drive。

第二級記憶体通常被设计成符合 文件系统 的格式，这使得资料可以儲存在 目錄 "目录 (文件系统)") 和 电脑檔案 內。

大部分的 作业系统 使用了 虛擬記憶体 的概念，第一級記憶体的物理容量雖然不变，但可以藉挪用第二級記憶体的空间来增大第一級記憶体的容量。系统会将最少使用到的区块移至第二級記憶体（ 置換檔案或分頁檔案），当这些檔案被需要时再将它们取回，当愈多檔案需要从第二級記憶体中取回，电脑的效能就愈低。

### 第三級記憶体

**第三級儲存裝置** 或 **第三級記憶体**, 这是指可直接插入或自电脑拔除的儲存裝置；里面的资料在被使用前通常都会复制到第二級記憶体內。该款記憶体的存取速度比第二級記憶体要慢得多（5–60秒，相较于1–10毫秒）。该款記憶体的優勢在于其擁有龐大的儲存空间，典型的例子包含 磁带櫃 和 光学記錄庫。
