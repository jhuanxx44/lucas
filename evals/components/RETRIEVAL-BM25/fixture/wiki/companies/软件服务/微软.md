# 微软

# 微软

微软

**微软**（英语：）是源自 美国 的 跨国科技公司，于1975年由 比爾·蓋茲 与 保羅·艾倫 创立，总部位于美国 华盛顿州 的 雷德蒙德 "雷德蒙德 (华盛顿州)")，与 亞马遜、 蘋果、 谷歌、 Meta 并列为五大 科技，同时为北美4大 云端服务提供者（CSP）之一。其中为研发、制造、授权及提供广泛的 电脑软体 服务为主要业务，最为着名且暢銷的产品是 Microsoft Windows 作业系统 及 Microsoft Office 办公软体，其它子公司如 Xbox 遊戲业务等也都十分的着名。

公司成立初期,主要为 Altair 8800 发展和銷售 BASIC 直译器，在1980年代中期藉着 MS-DOS 在 家用电脑 作业系统市场上取得长足进步，后来出现的 Windows 使得微软逐漸统治了家用桌面电脑作业系统市场。同时微软也开始扩大业务，进军其它行业和市场，建立了 MSN 网站，在 电脑硬体 市场上，微软商标及 Xbox 遊戲机、 Zune 和 MSN TV 家庭娛乐设備也在不同的年份出现在市场上。微软于1986年 首次公开募股，此后不断走高的股价为微软締造了四位亿万富翁和12,000位百万富翁。

隨着公司的强大，微软也受到越来越多的批评和责備，数十年来从未间断。拒絕交易和捆綁銷售等做法招致 垄断 和不正当競争的訴訟。 美国司法部 和 歐盟委员会 根据 反托拉斯法 均对微软做出过不利裁定。

截至2015年，尽管在 Android 和 iOS 的竞争下，微软已经失去了绝大部分行动裝置的系统佔比，但在 IBM PC 兼容操作系统市场和办公软件套裝市场仍占据主导地位。该公司还为台式机，筆記型电脑，标签，小工具和服务器生产各种其他消费者和企业软件，包括互联网搜索（与 Bing），数字服务市场（通过MSN），混合现实（ HoloLens），云计算（ Azure）和软件开发（ Visual Studio）。

史蒂夫鲍尔默于2000年取代盖茨担任首席执行官，后来设想了“设备和服务”战略。随着微软在2008年收购 Danger 公司，于2012年6月首次进入个人电脑生产市场，随着微软 Surface 系列平板电脑的推出，以及随后通过收购诺基亚设备形成微软移动和服务部门。自 萨蒂亚纳德拉 于2014年接任首席执行官以来，该公司业务已多元化，除了原先的 Windows 、 Office 和遊戲主机业务，还发展 Surface 系列和云服务，并更积極的参与开源，例如在2016年8月18日，宣布开源 PowerShell，并在Windows 业务、 Office 业务和 Xbox 业务之外新增对 Linux 平台的支援，发展 WSL，开源 Windows Terminal，收购 GitHub， .NET 框架 开源并跨平台，开源 VS Code，加强发展 Microsoft Azure 平台，Office 产品支援多平台。

2018年，微软曾一度超越 苹果公司，成为全球最有价值的上市公司。在2019年4月，微软达到了1美元的市值，成为仅次于苹果公司第二家股价市值超过1美元的美国上市公司（按： 亞马遜公司 2018年9月之盤中交易价即已曾超过1美元，但收盤时未能保持故不被视为正式紀錄）。2021年6月微软市值首次突破2美金，成为第二家市值突破2美金的公司。微软是美国 《财富》杂志 "财富 (杂志)") 2015年评选的 世界500强 企业排行榜中的第95名。

2014年2月4日， 微软 公司宣布由 萨蒂亚·纳德拉 接替 史蒂夫·巴尔默，成为新一任执行长。2021年6月16日，纳德拉同时担任微软董事长。

## 历史

### 起步（1975年–1984年）

蓋茨和艾倫和IBM签定合同后合影

微软公司是由 比爾·蓋茲 和 保羅·艾倫 在1975年创立的。他们是小时候认识的朋友及高中同学，并对电脑编程充滿激情。他们利用他们的演講技能，意圖追求成功。1975年1月，MITS公司发售了 Altair 8800 大众化微电脑和遥測系统，这令他们注意到，可以编寫一个BASIC直译器赚錢。他们致电给Altair 8800的发明者（ MITS），提出在该系统中执行 BASIC。MITS公司表示感兴趣，并要求艾倫和蓋茲进行示范。之后MITS公司聘请艾倫为Altair进行模擬器的开发工作，而蓋茲则开发直译器。他们的工作十分出色，1975年3月MITS公司同意出售 Altair BASIC。他们順利赚了第一桶金，于是蓋茲離开 哈佛大学，并搬到MITS在 新墨西哥州 阿布奎基 "阿布奎基 (新墨西哥州)") 的总部。1975年4月4日，微软正式成立，蓋茲为微软 执行长。他在1995年 《财富》雜誌 "财富 (杂志)") 的一篇文章中回憶，原名“Micro-Soft”是艾倫想出来的，之后更改为“Microsoft”。在1977年8月，公司和日本 ASCII雜誌 "ASCII (公司)") 签署了一个协议，成立了其首个国际办事处“ASCII Microsoft”。在1979年1月，公司搬迁到在華盛頓州 贝爾维尤 "贝尔维尤 (华盛顿州)") 的新办公室。

微软在1980年开发了 UNIX 作业系统业务，叫做 Xenix，并聘用 聖克魯茲作业 改编该作业系统以应用于不同操作平台。发表后受到歡迎，并鞏固了公司的霸主地位。1980年11月，微软获得了IBM公司的合同，这筆交易中，微软要提供 CP/M 作业系统给即将到来的IBM个人电脑。但微软没有时间开发一个全新的系统，于是微软从西雅圖电脑产品公司（英语：en:Seattle Computer Products）收购了 86-DOS，并将它更名为 MS-DOS，并授权给IBM使用；之后，IBM将自己获得的版本更名为 PC-DOS，并安装在1981年8月发布的IBM PC上，但微软仍保留了MS-DOS的所有版权。当时，因为IBM有PC-DOS的版权，所以其它公司无法在非IBM硬件上运行这一系统。但由于微软仍握有MS-DOS的所有版权，微软除了授权该软体给IBM使用外，还与其他OEM厂商谈判，将经过更改后的MS-DOS系统安裝到这些非IBM新电脑上。加上各种因素，微软最終成为了領先的个人电脑作业系统的系统供应商。从此在非IBM硬体上便可运行微软更改后的MS-DOS系统，从而完全改变了当时的电脑业的规则和生态。微软在1983年扩大业务，发布微软滑鼠，并成立 微软出版社 进入新的市场。但不幸的是，保羅·艾倫患上 霍奇金病，于同年2月向微软辭职。

### Windows和Office（1984年–1994年）

1984年，微软和 IBM 开始合作开发一款不同以往的作业系统 OS/2。
1985年11月20日，微软推出了首款 Microsoft Windows 的零售版，最初作为其MS-DOS系统的圖形拓展版本。于1986年2月26日，微软将其总部搬到雷德蒙德。1986年3月13日，公司 上市；股价的显着上升为微软締造了4位亿万富翁以及12000位百万富翁。由于与IBM的合作夥伴关系，导致1990年 联邦贸易委员会 开始对微软的監视；标誌着与美国政府超过十年的法律衝突的开始。1987年，微软終于为 原始设備制造商 提供了首款OS/2版本。OS/2有一个新的 模块化 "模组 (程式设计)") 內核 和 Win32 应用程式介面（API），基于MS-DOS的 16位元 Windows可更容易移植。但之后，OS/2的夥伴关系日趨惡化。

1990年，微软推出其办公套件 Microsoft Office。该软体綁定了办公室生产力应用程式，如 Microsoft Office Word 和 Microsoft Office Excel 等。5月22日，微软推出 Windows 3.0。Windows 3.0有精簡的用户介面，改进圖形效能和適合 Intel 386 处理器的改良。从此，Microsoft Office和Windows在各自領域佔据主导地位。

1994年7月27日， 美国司法部 提出的競争影響报告书的一部分称：“从1988年开始，直到1994年7月15日，微软誘导许多OEM厂商进行反競争行为。原装电脑制造商为每台电脑向微软支付版稅。”根据每台处理器许可证，原装电脑制造商会向其出售的每台包含特定微处理器的向微软公司支付特许权使用费，而无论原装电脑制造商出售的是装有微软还是非微软的。 如果没有使用任何微软产品，则对OEM（原装电脑制造商)使用竞争PC操作系统的行为应处以罚款或税收。自1988年以来，微软对每台处理器许可证的使用增加了。”

### 法律议題及网际网路（1995年–2007年）

比爾·蓋茲于1998年 美国訴微软案 出庭作证

1995年5月26日，比爾·蓋茲提出了“网际网路備忘錄”。1995年，微软开始重新定义其产品，并扩大并进入 电脑网路 产品线和 全球资讯网。该公司于1995年8月24日，发佈 Windows 95。具有先发制人的多工功能，新的 开始选单，和与32位元兼容的用户介面，并提供Win32 API。Windows 95捆綁了线上服务 MSN 和 IE。同时微软也开始扩张业务，进军其他行业和市场：与 NBC 合资建立 MSNBC，拓展有线电视新聞业务。微软发布 Windows CE 1.0，一个新的作业系统，设计为低記憶体设備提供簡单操作，如 PDA。1997年10月，司法部在 联邦地区法院 提交了一項议案，称微软违反1994年签署的一項协议，并要求法院责令微软停止将Internet Explorer捆綁于Windows。

2000年1月13日，比尔·盖茨将微软执行长的位置交给 史蒂夫·鮑爾默，然后为自己创造一个新的职位：首席软件架构师。2001年10月25日，微软发布 Windows XP，是首个使用产品啟用与盜版競争的Windows，然而Windows XP亦被部份使用者批评其安全漏洞与应用程式綁定（如Internet Explorer及 Windows Media Player）等。2011年9月底前，Windows XP是世界上使用人数最多的作业系统，在2007年1月，Windows XP的市场占有率达历史最高水平，超过76%。根据 Netmarketshare 公司对全球网路使用者的统计资料显示，2012年8月份，统治作业系统市场长达11年之久的Windows XP最終被 Windows 7 超越。Windows XP成为有史以来銷量最大及最常用的作业系统，更令下一代的 Windows Vista 慘澹收场（Windows Vista的市场占有率最高只有18%）。2004年，微软发布的 Xbox 遊戲机进入由 索尼 和 任天堂 主导的遊戲机市场。

### Windows Vista、Windows 7及行动裝置（2007年–2011年）

时任微软执行长史蒂夫·巴爾默

在2007年1月30日， Windows Vista 正式对普通用户出售。Windows Vista距離上一版本的作业系统 Windows XP 已有超过五年的时间，这是Windows历史上间隔时间第二久的一次发佈(最久为 Windows 11，间隔6年）。Windows Vista包含了 上百种新功能；其中较特別的是新版的 圖形用户介面 和称为「 Windows Aero」的全新风格（要求较高的硬体需求）、加强后的搜寻功能、新的多媒体创作工具（例如 Windows DVD Maker），以及重新设计的网路、音讯、输出（列印）和显示。Vista也使用 点对点技术 提升了电脑系统在家庭网路中的示通信能力，将让在不同计算机或裝置之间分享檔案与內容变得更簡单。针对开发者方面，Vista使用 .NET Framework 3.0版本，比起传统的 Windows API 更能让开发者能簡单寫出高品质的程式。Windows Vista是第一版只能支援在 NTFS 硬碟分割区上安裝Windows系统的Windows作业系统。

2008年6月27日，比爾·蓋茲退休后，除了重点項目加以指导外，而其餘时间都只当公司顧问。2008年10月27日推出的 Windows Azure 的服务平台，是该公司进入云计算入门市场上第一步。2009年2月12日，微软宣布有意圖开一个微软品牌连鎖零售店，并于2009年10月22日第一家零售商店在亞利桑那州斯科茨代爾正式开幕当天，微软正式发表 Windows 7。其易于使用的功能和性能增强，不但是一个大改造的Windows Vista，亦是Windows 7的重点。Windows 7将更「以使用者为中心」。Windows 7在执行程式方面上有较大的改进；微软将会在进步的前提下利用多种測量工具来測试作业系统，以增进其执行效率。Windows 7提高了螢幕触控支持和手寫识別，支持虛擬硬碟，改善 多核心 处理器的运作效率， 开机 速度和 内核 改进。

隨着智慧型手机行业的蓬勃发展，从2007年开始，微软努力保持与它的競争对手蘋果和谷歌的现代化的 行动作业系统 距離。微软于2010年4月12日上午在三藩市举行記者会，发表新一代智慧型手机。2010年10月，微软发佈 Windows phone 7。Windows Phone是一个 触控 操作模式 行动作业系统，采用Windows CE 7内核。而Windows Phone 8採用和Windows 8相同的内核。微软在发行这个作业系统时，主要的銷售对象是一般的消费市场，而非以前版本所瞄準的企业市场。在Windows Phone中，微软将其使用介面套用了一种称为“ Metro”的设计语言（曾被使用于 Zune 中），并将微软以及其它第三方的软体整合到了作业系统中，以嚴格控制执行它的硬体。微软更緊密地与智慧型手机制造商合作，如： 諾基亞。在 智慧型手机 行业的新战略，可望挽回失去的市场佔有率。

### Windows 8、Surface及收购諾基亞移动部门（2011年–2014年）

Surface RT

Windows 8 是微软公司改良研发中的下一代电脑 作业系统，Windows 8试圖打造一个可在平板电脑、手提电脑、桌上电脑和智能手机等都能使用的跨平台作业系统，被认为是微软反击主导平板电脑及手提电话作业系统市场的 蘋果电脑 iOS 和 Google Android 系统。该 软体 除了具備微软公司的传统 视窗系统 显示方式外，亦将强化更適合使用于 触控螢幕 的 平板电脑 设计，使用类似Windows Phone作业系统中动态方块（live tiles）界面，新系统可透过官方 网上商店 Windows Store 购买软体等新功能及特性。Windows 8于2012年8月第1周发布 RTM 版，并于10月26日正式上市。Windows 8.1中，微软发布了与Windows 8有区别的多个重要更新。微软公司于中原标準时间2013年10月17日发布Windows 8.1正式版。

平板电脑上， Microsoft Surface 是一系列以Windows 8为作业系统的 平板电脑。分別为Surface和Surface Pro，前者使用 輝达 处理器而后者使用 英特爾 处理器。并使用10.6英寸、长寬比16:9的高解析度螢幕。这款产品由微软 首席执行官 史蒂夫·巴爾默 在2012年6月18日于 洛杉矶 举行的記者会上公开。10月26日推出。雖然产品有多項新嘗试，但銷量并不理想，截至2013年5月僅售出150万部
。

2013年9月3日，微软宣布将以约72亿 美元 收购 諾基亞公司 幾乎全部的手机业务，当中购买设備与服务部门50亿，支付相关专利21.8亿。福布斯评论认为諾基亞是白菜价賤卖，“出售给微软并不驚訝，驚訝的是出售时间和价格”并且“ 史蒂芬·埃洛普 的动机将被仔細審视”。有媒体则指明埃洛普与微软的CEO职位令人遐想。

### Windows 10 和新一代 Surface（2014年–2021年）

2014年9月15日，微软公司宣布併购瑞典遊戲开发商 Mojang，包含公司所有权和遊戲（如该公司所开发的《 Minecraft》）的智慧财产权。收购金額为25亿美元。

2014年9月30日，微软在美国西雅图的新一代Windows操作系统的发布会中亮相 Windows 10 技术预览版，并声称正式版将于2015年后半年发行。

2015年7月29日，微软发布新版Windows 10，擁有多工管理介面、生物识别解锁（Windows Hello）及全新的瀏覽器 Microsoft Edge 等数百种功能。微软希望Windows 10能带动PC市场增长，并改善旗下 Windows Phone 的系统功能及生态环境。

2015年7月29日，微软 Windows 10 在全球 190 个国家同步上市，符合硬件资格的正版 Windows 7 、 Windows 8.1 及 Windows Phone 8.1 裝置均能免费升級，預估全球将有数亿 Windows 用户受惠。

2015年9月23日，微软在全球同步上市新版 Office 2016。

2015年10月7日，微软发布新一代Surface Pro产品，以及全新的 Surface Book，将Surface品牌扩大到笔记本领域。

2016年6月13日，微软以每股196美元的价格，斥资262亿美元现金收购商业社交平台 領英。

2016年8月2日，微软在官网宣布， Microsoft HoloLens 开发者版本已经在美国和加拿大开卖。

2016年10月26日，微软在秋季新品发布会上发布增强版的 Surface Pro 4 和 Surface Book，提高了其硬件配置。同时还发布了 Surface Studio 一体机和 Surface Dial 等辅助设备，将 Surface 硬件品牌再次扩大到纯桌面领域。

### 软体产品

微软生产的 软体 产品包括了以下很多的种类：

2014年9月23日，微软宣布将自家旗下的 云端硬碟 品牌 OneDrive 的免费用户永久儲存空间上调至15GB，使用備份照片可再次獎勵15GB。但此前尚未註冊的用户于2015年12月31日将会縮減至5GB，Office365的订阅用户不能繼续保持无限儲存空间。Microsoft程式的 終端使用者授权协定 经常被嚴厲批评。

### 裁员

2014年7月17日，微软公司宣布，受精简机构与整合诺基亚手机业务部门的影响，公司将在今后一年削减1.8万个工作岗位。其中，约1.25万被裁员工将来自刚刚并购过来的 诺基亚 设备与服务部门（主要为手机业务）。这将是公司历史上规模最大的一次裁员。

### 被入侵

2017年10月17日，5位前微软员工称，四年前微软用于追蹤自主软体漏洞內部资料庫被入侵，微软在2013年发现到资料庫被駭客入侵，但微软隨后并未公开被攻击的嚴重程度，5位前员工被採访描述此事件，微软拒絕回应。

### 藍屏死机

2024年7月19日，微软因CrowdStrike(CRWD.US)对「獵鷹感測器」软体的更新，导致其Windows 365云端PC出现了藍屏死机的问題，并登上全球新聞熱搜。
