# 微软出版社

## 概况

微软出版社（Microsoft Press）是微软的直属分支机构，成立于1983年[S1]，负责针对其产品与技术出版著作的事业部门，著作包含了一般性的入门书、教学手册、专家手册、参考用书等等[S1]。MCP考试的参考用书也是由微软出版社出版，称为「自学教材」(Self-Paced Training kit)[S1]。目前微软出版社配属于Microsoft Learning事业群中[S1]。

## 知名作者

微软出版社自成立至今，已培养出数位知名的技术作家，例如[S1]：

- Charles Petzold，以 Programming Windows 一书扬名国际，此书为公认的 Windows API 学习用书，目前已出至第六版[S1]。
- Jeff Prosise，其知名著作为 Programming Windows with MFC[S1]。
- Jeffrey Richter，以 Advanced Windows 一书扬名，被列为 Windows API 的进阶读物，目前则改名为 Programing Applications for Microsoft Windows[S1]。

## 知名书籍

微软出版社出版了多部知名书籍，以下为主要系列[S1]：

- **Programming Windows系列**，自1988年出版以来，被公认是 Windows API 的圣经级学习与参考用书[S1]。此书在台湾最早由松格资讯翻译，并分为上下两册 (Programming Windows 95)，后由华彩软件接手，目前则是由文魁资讯出版并销售[S1]。
- **Programming Windows with MFC系列**，公认的 MFC 学习用书，此书曾由台湾的松格资讯翻译为中文版，全书厚约1200页，目前由文魁资讯出版[S1]。
- **Windows Internals**，以描述Windows核心的内容为主，全书描写了Windows的系统层次架构，深受低阶或系统层次程序开发人员的喜爱[S1]。
- **Advanced Windows**，以描述高阶Windows API应用为主，后改名为Programming Applications for Microsoft Windows，与 Charles Petzold的Programming Windows 并列Windows开发人员必读圣典之一[S1]。

此外，微软出版社还出版了大量其他技术书籍，涵盖微软产品的各个方面，为技术社区提供了丰富的学习资源[S1]。
