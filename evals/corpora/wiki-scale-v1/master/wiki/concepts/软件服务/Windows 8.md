# Windows 8

## 概述

Windows 8是微软于2012年推出的Windows NT系列电脑操作系统。该操作系统除了具备微软适用于手提电脑和桌上电脑平台的传统视窗系统显示方式外，还特别强化适用于触控屏幕的平板电脑设计，使用了新的界面风格Metro。[S1] Windows 8于2012年8月1日向OEM厂商提供RTM版本；2012年9月1日起企业用户可以购买大量授权版本；2012年10月25日零售版本正式上市。[S1] 微软还于2012年10月推出自家第一款平板电脑Microsoft Surface，以推动Windows 8在平板电脑市场的地位。[S1] 2013年10月17日，微软发布Windows 8的内核升级版本Windows 8.1，供Windows 8用户免费通过商店更新。[S1]

## 版本与售价

Windows 8有四个主要版本：Windows 8（标准版）、Windows 8 Pro（专业版）、Windows 8 Enterprise（企业版）和Windows RT（ARM版）。[S1] 此外还有地区性廉价版本如Windows 8 Edition N（欧洲版）、Windows 8 Edition K/KN（韩国版）、Windows 8中文版等。[S1] 售价方面，盒装版在美国为119.99美元（标准版）和199.99美元（专业版）；中国大陆为人民币988元和1988元；台湾为新台币4,199元和6,999元；香港为港币1,369元和2,339元。[S1]

## 主要功能变化

Windows 8较前代在界面、启动、应用程序等方面增加新功能，同时也移除一些功能。新增加的功能包括：新版用户界面Metro（全屏应用）、Windows Store、支持ARM架构、原生USB 3.0和蓝牙4.0支持、文件资源管理器采用Ribbon界面等。[S1] 移除的功能包括Windows Aero毛玻璃效果、桌面小工具以及传统的开始按钮（任务栏不再显示开始按钮，但可通过热角或Windows键进入开始屏幕）。[S1] Windows 8共支持109种语言，比Windows 7增加14种。[S1] 取消开始按钮受到用户强烈批评，Windows 8.1中恢复了开始按钮。[S1]

## 硬件要求

Windows 8的硬件要求与Windows 7相似。x86（32位）和x86-64（64位）架构均需要1GHz或更快的处理器（支持SSE2、PAE和NX位），显示卡需支持WDDM 1.0或更高版本的DirectX 9绘图装置。32位系统内存要求1GB，硬盘16GB；64位系统内存要求2GB，硬盘20GB。ARM架构建议内存4GB以上，显示屏至少10英寸、分辨率1366×768以上，并需支持五点触控。[S1] 若要使用某些特定功能（如触控、Windows Store、贴齐应用等），还需满足附加要求，例如触控需多点触控设备，Windows Store需互联网连接且屏幕分辨率至少1024×768，贴齐应用需1366×768。[S1]

## 后续更新与评价

Windows 8因界面转变过快、缺乏开始按钮、Metro界面与桌面不协调等问题遭受批评，销量低迷。[S1] 微软于2013年推出Windows 8.1，增加个人化选项、开始按钮重回任务栏、开机可直接到桌面、整合Bing搜索和SkyDrive云服务、支持3D打印等。[S1] Windows 8的安全更新支持已于2016年1月12日停止（除Windows Embedded 8标准版外），Windows Embedded 8标准版的主流支持结束于2018年7月10日，延伸支持结束于2023年7月11日。[S1] 根据2024年4月StatCounter统计数据，Windows 8市占率仅0.09%。[S1] 此外，中华人民共和国工业和信息化部于2014年5月16日通过中国政府采购网发布通知，规范政府采购电脑不得安装Windows 8，理由是安全考虑。[S1]
