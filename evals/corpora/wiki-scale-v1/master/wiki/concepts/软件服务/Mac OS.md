# Mac OS

## 概述与历史

**麦金塔操作系统**（英语：Macintosh operating systems）是苹果公司自1984年以来为麦金塔（Mac）系列电脑开发的操作系统。[S1] 1984年，苹果公司发布了最初的麦金塔系统软件，推出了现在被称为 **Classic Mac OS** 的操作系统。[S1] 该系统原名为“**System Software**”，在1996年被重新命名为“**Mac OS**”；2001年，更名为“**Mac OS X**”；2012年更名为“**OS X**”；2016年更名为“**macOS**”。[S1] Mac OS X是在1997年至2001年苹果收购NeXT之后开发的，采用了基于UNIX的NeXTSTEP的全新架构，克服了Classic Mac OS所面临的许多技术挑战。[S1] 目前Mac的操作系统是macOS，预装在每台Mac电脑上，每年更新一次。[S1]

## Classic Mac OS

Classic Mac OS所指是苹果公司从1984年至2001年间为麦金塔系列电脑所开发的一系列操作系统，始于System 1，终结于Mac OS 9。[S1] 麦金塔操作系统因图形用户界面（GUI）概念的普及而受到赞誉。[S1] 在其开发时代所售出的每部麦金塔电脑中预装了最新的系统，对系统软件进行了许多更新。[S1] Classic Mac OS共有9个版本。[S1] 具体版本包括：
- Macintosh System Software – "System 1"，1984年发布 [S1]
- System Software 2, 3, and 4 – 1985-1987年发布 [S1]
- System Software 5 – 1987年发布 [S1]
- System Software 6 – 1988年发布 [S1]
- System 7 / Mac OS 7.6 – 1991年发布 [S1]
- Mac OS 8 – 1997年发布 [S1]
- Mac OS 9 – 1999年发布 [S1]

## Mac OS X/OS X/macOS

macOS（2011年及之前称**Mac OS X**，2012年至2015年称**OS X**）是苹果公司推出的基于图形用户界面的操作系统，为麦金塔（Macintosh，简称Mac）系列电脑的主操作系统。[S1] StatCounter在2018年8月的数据表示，在桌面操作系统中，macOS的使用份额为12.65%，次于Windows的82.51%位居第二。[S1] macOS是1999年发行的Classic Mac OS最终版本Mac OS 9的后继者。[S1] 1999年发布macOS Server的首个版本Mac OS X Server 1.0，桌面版Mac OS X 10.0「Cheetah」于2001年3月24日发布。[S1] 2012年苹果将Mac OS X更名为**OS X**，第一个使用此命名的系统为「OS X Mountain Lion」。[S1] 以前版本的macOS以大型猫科动物命名，但随着2013年6月OS X Mavericks的公布，命名开始采用加州地标。[S1] 2016年6月，苹果公司宣布OS X更名为**macOS**，以便与苹果其他操作系统iOS、watchOS和tvOS保持统一的命名风格。[S1] 最新版本macOS Big Sur已于2020年6月23日发布。[S1]

## 版本列表

该系统的第一个桌面版本于2001年3月24日发布。自2011年起，每年都有新版本发布。[S1] 具体桌面版版本如下：
- Mac OS X 10.0 – code name "Cheetah"，2001年3月24日向大众开放 [S1]
- Mac OS X 10.1 – code name "Puma"，2001年9月25日向大众开放 [S1]
- Mac OS X 10.2 – also marketed as "Jaguar"，2002年8月23日向大众开放 [S1]
- Mac OS X Panther – version 10.3，2003年10月24日向大众开放 [S1]
- Mac OS X Tiger – version 10.4，2005年4月29日向大众开放 [S1]
- Mac OS X Leopard – version 10.5，2007年10月26日向大众开放 [S1]
- Mac OS X Snow Leopard – version 10.6，2009年6月8日向大众开放 [S1]
- Mac OS X Lion – version 10.7，2011年7月20日向大众开放 [S1]
- OS X Mountain Lion – version 10.8，2012年7月25日向大众开放 [S1]
- OS X Mavericks – version 10.9，2013年10月22日向大众开放 [S1]
- OS X Yosemite – version 10.10，2014年10月16日向大众开放 [S1]
- OS X El Capitan – version 10.11，2015年9月30日向大众开放 [S1]
- macOS Sierra – version 10.12，2016年9月20日向大众开放 [S1]
- macOS High Sierra – version 10.13，2017年9月25日向大众开放 [S1]
- macOS Mojave – version 10.14，2018年9月24日向大众开放 [S1]
- macOS Catalina – version 10.15，2019年10月7日向大众开放 [S1]
- macOS Big Sur – version 11，2020年11月12日向大众开放 [S1]
- macOS Monterey – version 12 [S1]
- macOS Ventura – version 13 [S1]
- macOS Sonoma – version 14，2023年9月27日向大众开放 [S1]
- macOS Sequoia – version 15，2024年9月16日向大众开放 [S1]
- macOS Tahoe – version 26，2025年9月15日向大众开放 [S1]

此外，还有服务器版Mac OS X Server 1.0和macOS Server等。[S1] 整个操作系统家族还包括其他衍生系统，如iOS、iPadOS、watchOS、tvOS等。[S1]
