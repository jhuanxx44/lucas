# 微软认证

## 概述

**微软认证** 是 微软公司 所推动的 证照 制度[​S1]，分为个人与 微软合作伙伴认证 两大类，个人类认证于考生经指定科目的 认证考试，通过者授予相对应的证书与资格，用以证明其对于微软 软体 或是应用平台的专业能力，合作伙伴得以微软所规定的条件，符合条件者得授予不同的资格。目前全球已有超过二百三十万人取得认证资格[​S1]。 [S1]

微软认证早期是由 MCP，MCSE (Windows NT 3.51) 以及 MCSD ( WOSA) 所组成，随著微软产品的演进与扩张，接著推出 MCSE+I，MCP+I，MCP+SB 等认证，后期更推行了 MCDBA 以及 MCAD 等认证，直到 2005 年 SQL Server 2005 与 Visual Studio 2005 起，微软即将认证分成三阶段(Technology Specialist, Professional and Architect)[​S1]，作为 MCP 的继承者。 [S1]

2008 年微软更新认证的蓝图，加入MCM (Microsoft Certified Master) 认证。 [S1]

2012 年因应云端服务架构，修改认证的层次，恢复 MCSE/MCSD/MCSA 层次，并新加入 MCSM (Microsoft Certified Solutions Master) 认证。[​S1] [S1]

## 2012年起的认证架构

### 微软认证解决方案大师（Microsoft Certified Solutions Master，MCSM）

2012年，微软将原有的 MCM 认证升级，并更名为微软认证解决方案大师 (Microsoft Certified Solution Master)。[​S1] [S1]

### 微软认证解决方案专家（Microsoft Certified Solutions Expert，MCSE）

2012年10月，微软重新启用 MCSE 认证称号，目前国际最著名就是的MCSE，但名称已改为微软认证解决方案专家 (Microsoft Certified Solution Expert)，因应考古题泛滥以及认证与实务相差甚远的诟病，改采用新一代的云端解决方案，配合私有云建置、虚拟化、BI、自动化等，来识别认证的技能，并且以Solutions为主轴，IT技术为辅助，考试大幅加重了实作考题，和以前用认证的制度相比，解决(Solutions)字代表的是更广泛，较无明显界定的专业技术范围，且取消一试就发一张MCTS的制度，取消证照永久效用，改以两、三年再认证机制，减少85％认证数目，废除过期考试科目及证照。[​S1] [S1]

### 微软认证解决方案开发人员（Microsoft Certified Solution Developer，MCSD）

与 MCSE 并列为微软二大高阶认证之一，其认证方向是以程式开发人员 (Developer) 为主，通过此认证考试的专业人员会被视为具有使用微软应用平台，程式语言与技术发展企业解决方案的人员，由于目标是针对 **企业解决方案**，因此考试科目较著重于企业应用程式的开发，并不会太过于重视软体发展方法，以及程式语言本身。[​S1] [S1]

2012年，微软再次恢复使用 MCSD 认证的名称，以因应云端化以服务为基础的开发人员认证需求，并首波推出以 Windows Store App 以及 Web Application 为主的 MCSD 认证[​S1]。 [S1]

### 微软认证解决方案助理师（Microsoft Certified Solution Associate，MCSA）

2012年，微软重新启用MCSA称号，但名称已改为微软认证解决方案助理师 (Microsoft Certified Solution Associate)，并且不限系统工程师路线，开发人员路线也有 MCSA 认证[​S1]。 [S1]

### 微软认证专家（Microsoft Certified Professional，MCP）

微软认证中最早期，也是使用最久的认证称号，也有部份文章或介绍会以 **MCPS (Microsoft Certified Professional Specialist)** 来代表MCP，目前仅为微软认证专业人员计划 (Microsoft Certified Professional Program) 的缤写，只要通过任何一科微软发行的认证考试，即可取得MCP的资格。自2019年起，单独通过某门考试将不再提供MCP证书了。[​S1] [S1]

### 微软技术助理 (Microsoft Technology Associate)

微软技术助理认证是微软为技术入门者 (Entry Level) 所提供的入门级认证，难度比MCP等认证要简易一些，因为它锁定的是大专在学学生，而不是拥有一定经验与能力的IT工作者。主要的测验范围也都锁定在初阶的基础知识项目。MTA早期是专门给大专在学学生的考试，但2012年底微软宣布开放给社会人士，因此现在MTA不限学生，任何有兴趣的人都可以报考。[​S1] [S1]

### 微软专员 (Microsoft Specialist)

Microsoft Specialist 是一个特殊的认证，它虽然也是一个独立的认证，但是它的存在是给像 MCSD 这样的认证的基础需求所设定的。[​S1] [S1]

## 2005-2012年的认证架构

### 技术专精人员系列 (Technology Specialist Series)

微软认证技术专员 (MCTS) 是新一代的微软专业认证，并做为 MCP (Microsoft Certified Professional) 的继承者，持有 MCTS 代表对微软某个技术或某个产品具有充分的技术能力，可以执行 **组态设定 (针对网管或系统管理人员)** 或 **程式撰写能力 (针对开发人员)**，MCTS 是以 **产品** 和 **技术** 为认证的标的，与前一代的 MCP 系列不同，每一个 MCTS 认证均只有一科考试科目，只要通过该科考试，即可取得 MCTS 资格。[​S1] [S1]

### 中阶专业人员系列 (Professional Series)

微软新一代认证的中级认证，分为 MCITP 以及 MCPD 两种，分别代表系统管理员与程式开发人员的中级认证，与 MCTS 类似，是以特定技术领域为认证标的，但 MCITP 与 MCPD 的认证目标，是测验考生对于目的职务 (job) 的工作胜任能力，与 MCTS 只单纯测验产品熟悉度完全不同，考试内容可能会包含设计，规划，发展，评量与计划制定等特殊的能力，而这些能力都是专注在特定的职务上，像是系统工程师以及系统分析师之类的职务。正由于所认可的方向完全不同，因此单一认证可能需要多于一科的考试，并且也有前置的 MCTS 考试需求。MCITP 与 MCPD 的考试以 PRO 为前置字，代表其考试为专业级考试。[​S1] [S1]

### 高级专家系列 (Master Series)

微软认证高级专家是微软在 2008 年新推出的认证，作为微软三阶段认证中的最高级认证，并将MCA认证独立出来成为一个独立计划，MCM认证将会作为申请MCA考试的前置需求。根据微软的定义，微软认证高级专家可以从事其认可领域中的高级能力，举凡规划、设计、发展、建置、部署、支援、维护与问题排除等都可以执行，也因为高级专家认证必须要有如此高深的能力，因此微软在高级专家认证计划中加入了培训的条件，也就是每一位高级专家的考生都必须要在微软总部受训三个星期，并且通过微软举办的笔试以及实验室考试后，才可以被授予高级专家的认证。[​S1] [S1]

### 架构师系列 (Architect Program)

MCA 是微软新推出的最高阶认证，代表对 MCA 所测验的领域有著高级或专家水准等级的技能与知识，可以在企业中规划与推行 企业资讯架构 (IT Architecture)，由需求分析，规划，设计，发展，部署，建置与维运等周期所需要的工作，都可以胜任。MCA 分为两种，一种是无视任何技术（亦即不一定只测验微软本身的技术，其他竞争对手的也会被测验到）的广度技术架构师 (Broad Architect)，另一种则是以特定微软产品为主的深度架构师 (Depth Architect)，又被称为技术架构师 (Technology-based Architect)。[​S1] [S1]

## 2005年之前的认证架构

### 微软认证专家（Microsoft Certified Professional，MCP）

微软认证中最早期，也是使用最久的认证称号，也有部份文章或介绍会以 **MCPS (Microsoft Certified Professional Specialist)** 来代表MCP，目前仅为微软认证专业人员计划 (Microsoft Certified Professional Program) 的缤写，只要通过任何一科微软发行的认证考试，即可取得 MCP 的资格，不过下列三科考试除外：Exam 70-058: Networking Essentials；Exam 70-240: Microsoft Windows 2000 Accelerated Exam for MCPs Certified on Windows NT 4.0；Exam 70-536: TS: Microsoft .NET Framework, Application Development Foundation。[​S1] [S1]

### 微软认证系统工程师（Microsoft Certified System Engineer，MCSE）

MCSE 是微软认证中的高阶认证之一，代表持有认证的专业人员，对微软的伺服器，网路技术，系统管理的建置，管理，部署以及维护等工作具有相当的经验与知识，适合网路工程师，系统管理员，系统工程师或网路管理师等职务，在早期与 MCSD 并列微软的两大高阶认证，最早的版本是 Windows NT 3.51，接著在每个 Windows Server 的版本更新，就会更新 MCSE 的认证要求。[​S1] [S1]

### 微软认证解决方案开发人员（Microsoft Certified Solution Developer，MCSD）

与 MCSE 并列为微软二大高阶认证之一，其认证方向是以程式开发人员 (Developer) 为主，通过此认证考试的专业人员会被视为具有使用微软应用平台，程式语言与技术发展企业解决方案的人员，由于目标是针对 **企业解决方案**，因此考试科目较著重于企业应用程式的开发，并不会太过于重视软体发展方法，以及程式语言本身。早期的 MCSD 是以 WOSA (Windows Open System Architecture) 为主，考验开发人员对 Windows 环境的熟悉度，然后搭配两科与应用程式开发有关的考试作为选考科目，当时微软有将 MFC 以及 OLE 开发等纳入选考科目中，以及当时初次进入认证考试的 Visual Basic 5.0 产品。[​S1] [S1]

### 微软认证资料库管理员（Microsoft Certified Database Administrator，MCDBA）

MCDBA 为微软针对 SQL Server 资料库所推出的独立认证，特别针对 资料库管理员 所设计，持有此认证的专业人员，可被视为具有管理 SQL Server 以及设计资料库应用的专业能力与知识。MCDBA 最早是自 SQL Server 7.0 开始推出，历经 SQL Server 2000 时期，两个时期的认证要求差不多，都是要求通过四科考试，包含资料库系统管理，资料库设计，伺服器作业系统管理以及选考科目。[​S1] [S1]

### 微软认证应用程式开发人员（Microsoft Certified Application Developer，MCAD）

MCAD 为微软在 .NET Framework 1.0-1.1 时期，为了与 MCSD 工作项目有所区分，并且不是所有人都具有系统分析能力的情况下，所加入的认证资格，持有此认证表示具有应用 Microsoft .NET 技术发展应用程式的能力，应用程式不一定要 Windows 与 Web 都精通，但一定要会 XML Web Service 和伺服器端的开发，这些需求也反应到了考科之上。[​S1] [S1]

### 微软认证系统管理人员（Microsoft Certified System Administrator，MCSA）

MCSA 是在 Windows 2000 的后期登场，主要原因是 MCSE 的考科数过多，而且多数的网路管理人员并不需要对设计网路架构所有涉猎，因此考科可降为四科，其中有一科是专为 MCSA 所设计的 Exam 70-218: Managing a Microsoft Windows 2000 Network Environment，其实此科为 Exam 70-216 以及 70-217 二科考试，针对系统管理的角色所重新设计的考试，其他考试则与 MCSE 相似。到了 Windows Server 2003 时期，微软即不再为系统管理员设计考试，而是将原有的考试科目纳入 MCSA 的考科中。[​S1] [S1]

### 微软认证桌面支援专员（Microsoft Certified Desktop Support Technician，MCDST）

MCDST 首次推出是在 Windows XP 时期，微软发现在桌面作业系统以及应用程式维护的需求增加，而现有的 MCSE 与 MCSA 又过于偏向企业级应用环境，因此微软特别为桌面应用环境设计了 MCDST 认证，持有此认证的专业人员被视为对 Windows XP 的用户端作业系统以及其上的应用程式的维护与技术支援的能力，能够针对安装 Windows XP 的电脑执行维护与故障排除工作。[​S1] [S1]

## 不受年度影响的认证架构

### Microsoft Office使用者专家认证

应用程式使用者系指使用 Microsoft Office 的使用者群，微软针对了Microsoft Office的使用者设计了MOS (Microsoft Office Specialist) 认证，用来测验考生对Microsoft Office应用程式的操作能力，MOS的考试多是以实机测验 (Performance-Based Exam) 为主。因应Office 2007的推行，微软发布了新一代MOS的继承者：MCAS (Microsoft Certified Application Specialist) 与 MCAP (Microsoft Certified Application Professional) 两种认证，并且整并了 MOS、MCAS 与 MCAP 三个认证，合称为 **微软商务认证 (Microsoft Business Certifications)**，但因为某些因素，Office 2010年时又恢复使用MOS认证计划。[​S1] [S1]

### Microsoft Dynamics 认证

Microsoft Dynamics 认证是针对微软的商业解决方案产品群所设计的认证，分为专员级与专家级两种。MCBMSS 专员级认证是以 Microsoft Dyanmics 产品中的特定模组应用的技能设计，例如 Microsoft Dyanmics AX 的财务管理模组有一科考试，或是 Microsoft Dyanmics SL 的安装与设定有一科考试等，每科考试都代表一个模组的使用、管理、开发或维护等。MCBMSP 专家级认证则是将 MCBMSS 考试以及和微软产品的整合，组成以特定工作 (job) 为测验标的的认证系统，例如 Applications for Microsoft Dynamics CRM 4.0、Developer for Microsoft Dynamics NAV 与 Installation and Configuration for Microsoft Dynamics SL 等。[​S1] [S1]

### 教育训练认证

MCT 与 MCLC 为微软特别为专业级讲师以及学习顾问的认证，在微软的教育训练体系中，具有 MCT 的讲师才可以在微软认可的教育训练中心 (Microsoft Certified Partner: Learning Solution) 中，使用微软的教材 (Microsoft Curriculum) 来授课，而且 MCT 是一种具有期限的认证，其考试方式也因各国的情况而有所不同。MCLC 则是具有经验的 MCT，透过展示学习路线规划能力的测验才可以取得，证明其具有学习与训练的规划能力。[​S1] [S1]

## 已经终止的认证

- **微软认证系统工程师兼网际网路专长 (Microsoft Certified Systems Engineer + Internet，MCSE+I)**
- **微软认证专业人员兼网际网路专长 (Microsoft Certified Professional + Internet，MCP+I)**
此为微软在网际网路初期推广 Windows NT Server 4.0 以及 IIS (当时为 3.0 与 4.0) 时所推出的认证，MCP+I 是设计给初阶的网管工程师，MCSE+I 则是设计给高级的系统工程师，MCSE+I 也是微软少数考试科目数量超过七个的认证。MCP+I 要求三科考试，MCSE+I 要求九科考试。[​S1] [S1]
- **微软认证专业人员兼网站建构专长 (Microsoft Certified Professional + Site Building，MCP+SB)**
此为 MCSE+I 和 MCP+I 同样时期推出的认证，设计给专门开发网站的专业人员，它要求由三科考试中选考二科。[​S1] [S1]

## 考试方式

微软认证的考试多以电脑笔试方式进行，现时由 VUE 提供微软的考试服务，(MOS、MCAS与MCAP考试则是由 **Certiport** 提供)，考生可以在当地的 **授权考试中心** (Authorized Testing Center) 参加考试，考试费用在北美是125美元，微软的考试代码以 **070** 开头，例如070-640 为微软Windows Server 2008的 Active Directory 组态考试。考生在考完试后可以马上拿到成绩单，成绩单会列出考试 **通过分数 (PASS SCORE)** 与考生得到的分数，部份考试还会列示出考试所测验的各个主题的得分情况，让考生可以知道需要再加强哪些地方。[​S1] [S1]

不过微软在 MCSE on Windows NT 4.0以及MCSE on Windows 2000的时期，发现有许多考生利用不正常的手段（像是Braindump，买考题背答案等等）通过考试，因此微软开始著手研发新的考试题目类型，并且开始在MCSD, MCSE on Windows Server 2003等考试中运用，微软将这些改变称为Testing Innovations[​S1]。 [S1]

## 考试的发展与测试型考试

微软在 MCP 系列的中的考试，均依照微软内部的规划，并经常八道程序来发展：
1. 工作分析 (Job analysis)。 [S1]
2. 目标领域定义 (Objective Domain Definition)。 [S1]
3. 计划调查 (Blueprint survey)。 [S1]
4. 试题发展与命题 (Item development)。 [S1]
5. 初步检阅 (Alpha Review) 与试题校订 (Item revision)。 [S1]
6. 发布测试型考试 (Beta exam)。 [S1]
7. 决定最终题库中的试题，并决定通过分数 (Item-selection and cut-score setting)。 [S1]
8. 推出正式考试 (Live Exam)。[​S1] [S1]

在微软推出新产品并发展考试的第六阶段，会在一定期间内推出 **测试考试 (Beta Exam)**，测试考试以 **71** 开头，在测试考试期间，只要有收到微软寄发的邀请函，即可利用邀请函中的 **优惠码(Promotion Code)** 报名，可以减免所有的考试费用，考生在考完测试考试后，并不会马上得到成绩单，而是在考试进入 **正式考试 (Live Exam)** 阶段后，才由原厂寄发成绩单，同时考试供应商的网站的个人考试记录中也会更新。若测试考试达到通过成绩时，视同通过正式考试，可获得认证资格。[​S1] [S1]

## Charter 认证资格

- 在微软考试进入 Live Exam 状态后，在一定期限 (大多为六个月) 或是一定数量的名额内通过者，可以获得 Charter 等级的证书，在早期被称为 Early Bird 或 Early Archive，意思是率先取得认证者。
- 只要是在 Beta 考试时就通过的考生，都可以拿到 Charter 认证资格。[​S1] [S1]

## 有效期限

视认证的不同，有不同的有效期限：
- MCP, MCSE, MCSD, MCAD, MCDBA, MCSA, MCDST：永久有效。
- MCTS：在所对应的产品主流支援生命周期结束后失效（大约是5-8年）。 [S1]
- MCPD, MCITP：一开始规划的有效期是三年，后来改为与 MCTS 相同。
- MCT, MCLC: 每年都需要申请更新认证。
- 新规 MCSE 每3年要重新认证一次，而 MCSD 每2年需重新认证一次。[​S1] [S1]
