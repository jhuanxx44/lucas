# 应用服务器

## 定义

**应用服务器**（英语：application server）是一种软件框架，提供一个应用程序执行的环境。用于为应用程序提供安全、数据、事务支持、负载平衡、大型分布式系统管理等服务。这个名词最初是用来讨论主从式架构系统时，用来区分数据库服务器、文件服务器等的不同。但现今常指能运行Web应用程序的Web服务器。[S1]

## 种类

应用服务器根据开发平台可分为多种类型，主要包括：[S1]

### Java
- EJB
- Java EE
  - GlassFish
  - JBoss
  - Apache Tomcat
  - WebLogic
- 或是其它可以运行JSP的Web-Server[S1]

### .Net Framework
- Microsoft：通常指安装过.Net Framework的Microsoft Windows Server的IIS
- 第三方套件：
  - Mono
  - 四进制[S1]

### PHP
- Zend Server
- HHVM[S1]

## 使用应用服务器的优点

应用服务器具有以下优点：[S1]
- 数据与代码的完整性
- 集中配置与管理
- 安全性
- 执行效能
- 总拥有成本（TCO）
- 可支持交易机制[S1]
