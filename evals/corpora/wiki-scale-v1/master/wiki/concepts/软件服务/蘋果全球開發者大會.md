# 苹果全球开发者大会

## 概述

苹果全球开发者大会（WWDC）是苹果公司每年定期于美国加州举办的信息技术活动，旨在向全球软件设计师展示苹果公司最新的软件及技术，通常用于展示MacOS、iOS、iPadOS、watchOS、tvOS和VisionOS系列以及其他苹果公司的软件。与会者可以与苹果公司工程师一起参与动手实验，并参与涵盖各种主题的深入会议。[S1]

首届WWDC于1983年举行，与会者首次预览了Lisa；从2002年起，苹果开始将该会议作为发布新产品的主要平台。[S1] 1987年的WWDC在圣克拉拉举行，1988年至2002年在圣何塞举行，2003年至2016年移至旧金山，2017年回到圣何塞。受COVID-19安全限制影响，会议曾转为线上；2023年的WWDC采用线上与线下并行形式。[S1]

## 活动内容

WWDC于每年六月的一个星期周一至周五举行。会议主要包括一个主题演讲、演示会、一对一的「实验」咨询，以及特别的聚会和活动。[S1] 所有参与人士必须签署涵盖WWDC议程及会议其他资料的保密协议。WWDC的演示片段也包含于保密协议中。然而，近年苹果公司改以线上直播的方式向全世界公开。[S1]

会议以蒂姆·库克与苹果公司其他高管人员于周一早上的主题演讲作为开始（从1998年到2011年史蒂夫·乔布斯辞职和去世，乔布斯发表的主题演讲，媒体常称其为Stevenote）。由于苹果公司会定期在活动中发布产品，出席者与媒体都会参与会议。活动期间发布的硬件有时会于随后在会议厅展出。下午的主题演讲后就是平台状态演讲，它强调并展示了苹果公司软件开发平台的变化。苹果设计大奖也在会议的第一天宣布。[S1]

不同的会议环节会从周二到周五同时进行。演示文稿覆盖编程、设计和其他主题，范围从入门到进阶。几乎所有预定安排的演讲都是由苹果公司员工提供。这些演示是实时网络直播传输，而录制片段可以在苹果开发者网站上的会议iOS与tvOS应用程序中按需要查阅。午餐时间由各种科技领域专家作嘉宾主持演讲；这些环节都不会有串流传输或录制。[S1] 在过去，一些会议环节包括了问答时间，而受欢迎的环节「Stump the Experts」则以苹果公司员工跟出席者的互动为特色。[S1]

在整个星期进行的实验中，苹果公司的工程师将会与开发人员出席一对一的咨询。用户界面设计和电脑辅助功能方面的专家也可以预约咨询。[S1]

苹果公司在会议期间为各种小组团体组织社交聚会，例如STEM领域的女性或对国际化与本地化或机器学习感兴趣的开发人员。在附近公园举行的星期四晚狂欢节（以前称为啤酒狂欢节），为所有21岁或以上的参加者提供现场音乐、食物和饮料。[S1]

## 门票与参与

参与该大会需要支付$1,599美元的门票[S1]，门票是通过线上抽签获得。参加者必须年满13岁，并且必须是苹果开发者计划的成员。[S1] 奖学金适用于学生和理工科（STEM）组织的成员。[S1] 直到2007年，参加人数在2,000至4,200之间不等；然而，在2007年WWDC期间，史蒂夫·乔布斯于其简报内指出有超过5,000名参与者，是历届最多人参与的大会。2008年至2015年举行的WWDC活动设上限，5,000名参与者门票全数售罄（包括特别参加者为5,200人）。2018年WWDC有来自77个国家的6,000名参会者，当中包括350名奖学金得奖者。[S1]

## 历史

### 1980年代

首届WWDC于1983年举行，被称为苹果独立软件开发者大会。参与者必须签署保密协议，但已知的是人们首次率先看到世界上第一台具有图形界面的个人电脑——Lisa。[S1] 1984年，乔布斯向开发人员推出了麦金塔电脑，这也是首年该活动向媒体开放。[S1] 1989年，System 7于该年公布。[S1]

### 1990年代

1991年，WWDC见证了QuickTime的首个公开演示。[S1] 1995年的WWDC几乎把焦点完全专注于Copland操作系统的计划。1996年的首要重点是一种名为OpenDoc的新软件组件技术。1997年的WWDC标志着乔布斯以顾问回归，收购NeXT后，将焦点放在使用OpenStep作为下一代Mac OS的基础。1998年，引入了Carbon API和Quartz成像模型。1999年，主要公告包括Darwin操作系统的开放、Finder的改进，以及使用OpenGL替换QuickDraw 3D作为主要3D API。[S1]

### 2000年代

2000年，Mac OS X发布前的进度报告，包括修改的Dock和开发者工具改进版本。2001年，增加了Mac OS X Server和WebObjects 5的第一个版本。2002年，推出Mac OS X v.10.2、QuickTime 6和Rendezvous（现名Bonjour），并以模拟葬礼向Mac OS 9告别。2003年，展示了Power Mac G5、预览了Mac OS X Panther（10.3）、宣布Safari 1.0。2004年，预览了Mac OS X Tiger（10.4）和iTunes 4.9。2005年，宣布Macintosh平台从PowerPC过渡至Intel x86架构。2006年，推出Mac Pro和Xserve更新，公布Mac OS X Leopard的10项改进。2007年，推出Mac OS X Leopard的完整测试版、Safari for Windows，以及首次超过5,000名参与者。2008年，推出App Store、iPhone 3G、iOS 2.0和Mac OS X Snow Leopard。2009年，推出iPhone OS 3.0、Mac OS X Snow Leopard展示、新MacBook Pro和iPhone 3GS。[S1]

### 2010年代

2010年，推出iPhone 4、将「iPhone OS」更名为「iOS」、FaceTime和iMovie。2011年，推出Mac OS X Lion、iOS 5和iCloud；这是乔布斯主持的最后一次苹果活动。2012年，推出苹果地图、新款MacBook Air/Pro、OS X Mountain Lion和iOS 6。2013年，推出重新设计的Mac Pro、OS X Mavericks、iOS 7、iWork for iCloud和iTunes Radio。2014年，推出iOS 8、OS X Yosemite和编程语言Swift。2015年，推出iOS 9、OS X El Capitan、watchOS 2、Swift开源和Apple Music。2016年，将OS X更名为macOS，推出macOS Sierra、iOS 10、watchOS 3、tvOS 10、HomeKit应用和Swift Playgrounds。2017年，推出iOS 11、watchOS 4、macOS High Sierra、iMac Pro、10.5英寸iPad Pro和HomePod。2018年，推出iOS 12、macOS Mojave、watchOS 5和tvOS更新，无新硬件。2019年，推出iOS 13、macOS Catalina、watchOS 6、tvOS 13、iPadOS 13、Mac Pro和Pro Display XDR。[S1]

### 2020年代

2020年，因疫情转为线上，推出iOS 14、iPadOS 14、tvOS 14、watchOS 7、macOS Big Sur，以及苹果自研ARM处理器。2021年，线上举行，推出iOS 15、iPadOS 15、tvOS 15、watchOS 8、macOS Monterey。2022年，线上为主，推出iOS 16、iPadOS 16、tvOS 16、watchOS 9、macOS Ventura、M2 MacBook Air和13英寸MacBook Pro。2023年，线上加线下并行，推出macOS Sonoma、Apple Vision Pro、iOS 17、iPadOS 17、watchOS 10、tvOS 17、Mac Pro、M2 Ultra Mac Studio、15英寸MacBook Air。2024年，免费线上参与，发布各系统更新。[S1]

## 苹果设计大奖

苹果设计奖是每年WWDC期间颁发的设计奖项，旨在表彰每年iOS、macOS、watchOS、tvOS等苹果平台上在设计、技术和创新方面有杰出表现的软件、硬件开发者。[S1]
