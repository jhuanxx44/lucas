# Tesla Model X

## 概述
特斯拉Model X（简称X型）是由美国特斯拉汽车公司开发的高性能电动运动型多用途车（SUV），于2015年9月上市。Model X为该公司车身尺寸最大的乘用车，鹰翼门是此款车的最大特色之一，后侧门能以向上延展方式掀开，同时侦测侧边及上方的障碍物避免碰撞，达到即便在狭窄的空间范围仍可轻松进出。[S1] 2020年，X型成为新的NASA、SpaceX太空人运送车，取代Astrovan露营车。[S1] 来源规格表将Plaid版0-100km/h加速列为2.6秒，但同页正文另称2.5秒，两种数值存在冲突。[S1]

## 车型设计
根据特斯拉公司的行政总裁艾伦·马斯克的说法，如果是在正面或侧面发生碰撞，Model X为同类中最安全的车型。在翻车测试中的结果也显示，Model X的安全性也比其他类似的SUV高出两倍以上。而该车的防撞系统拥有一个自动紧急制动系统及一个可以紧急控制车辆进行转向的侧向超声波检测。其他设计还包括一个全景挡风玻璃加天窗、鹰翼式车门及一个可以选择芯片的标配自动驾驶仪。[S1] Model X是目前特斯拉最大载物空间的轿车车款，载物量高达2577公升。内饰配置有可折叠的三排座位选择，可容纳7名成人，并有车辆前后的行李放置空间。[S1] 该车型的方向盘和每个座椅皆设有加热装置，而前座在2021年新增通风座椅功能。[S1] 跟特斯拉Model S一样，在驾驶座设有一个位于方向盘后面的显示器，一个17吋的中央触控屏幕，也有一个8吋的后座触控屏幕。[S1] 其中央触控屏幕可操作空调、倒车镜头、自动车门、空气悬架高度、雨刷喷嘴加热除霜和网页浏览器等其它功能。[S1] 2021年新增的后座触控屏幕可供后座乘客操控空调、玩电子游戏等其它功能。[S1]

## 性能与规格
Model X采用三相异步电动机，功率310 kW（416 bhp），扭矩600 N·m（443 ft·lb），单速固定齿比变速器（9.73:1），电池容量100 kW·h锂离子电池，最高支持250 kW充电。[S1] 轴距2,964 mm，长度5,037 mm，宽度1,999 mm，高度1,676 mm。整备质量：Long Range版2352 kg，Plaid版2455 kg。[S1] 规格型号对比：
- 75D（2016年）：EPA续航383公里，0-100km/h加速6.2秒，双组驱动马达 [S1]
- 100D（2018年）：EPA续航475公里，加速4.9秒，双组 [S1]
- Long Range Plus（2020年）：EPA续航597公里，加速4.6秒，双组 [S1]
- Base（2021年）：EPA续航565公里，加速3.9秒，双组 [S1]
- Plaid（2021年）：EPA续航536公里，加速2.6秒，三组驱动马达[S1]
Model X动力布局为258。[S1]（注：来源表格中“动力布局”列显示“258”，意义未明确）

## 生产与停产
Model X生产日期为2015年至2026年，样式年份2021，装配于美国加州费利蒙特斯拉工厂，设计师为Franz von Holzhausen。[S1] 车辆类别为全尺寸SUV，车体风格5门SUV，相关车型包括特斯拉S型和Y型。[S1] 特斯拉首席执行官伊隆·马斯克于2026年1月宣布将停产Model S与Model X，将产能分配给Optimus机器人。[S1] 2026年5月10日，最后一辆Model X在美国弗里蒙特工厂下线，该车正式停产。[S1]

## 召回
- 2016年，因第三排座椅的锁定链故障风险，在美国召回2,700辆2016年3月前生产的X型[S1]
- 2017年，因手煞车系统失效风险，在全球召回53,000辆2016年10月前生产的S型和X型[S1]
- 2020年，因方向盘失效风险，在北美召回15,000辆2016年10月前生产的X型[S1]
- 2020年，因前悬架后连杆球头螺栓受冲击后产生裂纹和断裂风险，在中国大陆召回29,000辆2017年8月前进口的S型和X型[S1]
- 2020年，因车顶装饰板黏接不当风险，在美国召回9,100辆2016年8月前生产的X型[S1]
- 2021年，因触控式面板故障风险，在美国召回135,000辆2018年4月前生产的S型和X型[S1]
- 2021年，因悬吊系统损坏风险，在台湾召回2017年3月至2017年6月间生产的X型[S1]
- 2021年，因安全气囊破裂风险，在美国召回7,600辆2021年间生产的S型和X型[S1]
