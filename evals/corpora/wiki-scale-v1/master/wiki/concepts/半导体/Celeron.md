# Celeron

## 概述

赛扬（Celeron）是英特尔公司中央处理器的一个注册商标，首款产品于1998年4月15日发布，定位为比奔腾（Pentium）低阶的经济型产品。2006年酷睿处理器推出后，赛扬成为比奔腾更低阶、但比凌动（Atom）高阶的产品线。2022年9月，英特尔宣布在笔记本端不再使用赛扬品牌，取而代之的为“Intel Processor”品牌；桌面端至今仍在生产。 [S1]

## 产品历史

### P6架构时代（1998–2002）

- **Covington**：首批赛扬，基于Pentium II移除了片外512KB半速二级缓存，仅推出266MHz和300MHz型号，因无L2缓存整数性能低下，但超频能力较强。 [S1]
- **Mendocino**：配备128KB片内全速L2缓存，频率300–533MHz，其中Celeron 300A因超频至450MHz而闻名，极大提升了赛扬的市场份额。 [S1]
- **Coppermine-128**（赛扬2）：采用180nm制程，外频66MHz或100MHz，与AMD Duron竞争时靠稳定性和低功耗取胜。 [S1]
- **Tualatin-256**（赛扬3）：0.13μm制程，256KB L2缓存，外频100MHz，超频至133MHz后性能与同代奔腾III无异，被中国大陆玩家称为“图拉丁”。 [S1]

### NetBurst架构时代（2002–2007）

- **Willamette-128**（赛扬4）：首次采用Pentium 4架构，128KB L2缓存，性能甚至不如1.2GHz的Tualatin赛扬。 [S1]
- **Northwood-128**（赛扬4）：130nm制程，降低电压，Celeron 2.0A可超频至2.66GHz，但性能差距仍被拉大。 [S1]
- **Celeron D**：分为Prescott-256（90nm，256KB L2，533MHz FSB，支持EM64T）和Cedar Mill-512（65nm，512KB L2，全系列支持EM64T）。 [S1]

### Core微架构时代（2007–2010）

- **Conroe-L**（Celeron 400系列）：单核心，65nm，512KB L2，800MT/s FSB，性能优于Celeron D 365。 [S1]
- **Celeron Dual Core E1系列**：首款双核心赛扬，Conroe核心，512KB L2，如E1200（1.6GHz）。 [S1]
- **Celeron Dual Core E3系列**：45nm Wolfdale核心，1MB L2，首次在赛扬中引入VT-x技术，如E3200、E3300等。 [S1]

### 后续架构

自Sandy Bridge微架构后，赛扬分为Celeron G（桌面）、Celeron J、Celeron N、Celeron U等系列。移动版赛扬包括Tualatin-256、Northwood-256（Celeron M）、Banias、Dothan、Yonah、Merom、Penryn等核心。 [S1]

## 与奔腾的主要区别

赛扬作为同代奔腾的简化版，主要差异包括：
- 二级缓存、三级缓存容量显著缩减（如Covington无L2，Mendocino仅128KB，而奔腾通常有512KB或更多）。 [S1]
- 指令集（如MMX、SSE等）往往落后一代。 [S1]
- 部分技术（如VT-x、超线程、DEP、SpeedStep）延后或从未引入。 [S1]
- 前端总线频率较低（如赛扬常为66MHz或100MHz外频，奔腾为133MHz或更高）。 [S1]

但赛扬因较低的倍频和简化的缓存，常具有较好的超频潜力，如Celeron 300A可超频50%达到450MHz。 [S1]

## 品牌演变与命名规则

赛扬品牌下曾出现多种后缀：
- **A**：区分同频率的新旧核心（如Celeron 300A）。 [S1]
- **D**：采用Prescott核心的Celeron D。 [S1]
- **J**：支持执行禁用位（EDB）功能。 [S1]
- **M**：移动平台版本。 [S1]

非官方但常见的称呼有“赛扬2”（Coppermine-128）、“赛扬3”（Tualatin-256）、“赛扬4”（Willamette/Northwood核心）。 [S1]

2022年9月，英特尔宣布笔记本端赛扬品牌被“Intel Processor”取代，而桌面端赛扬仍继续生产。 [S1]
