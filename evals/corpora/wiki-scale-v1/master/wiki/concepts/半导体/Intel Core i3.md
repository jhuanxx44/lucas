# Intel Core i3

## 概述

**Core i3**（中文：酷睿 i3）处理器是英特尔的首款 CPU + GPU 产品，首代 Core i3 基于 Westmere 微架构 [S1]。Core i3 整合一些北桥的功能，集成 PCI Express 控制器、内存控制器和 Intel HD Graphics [S1]。处理器核心方面，首代 Core i3 的代号是 **Clarkdale**，采用32纳米制程 [S1]。Core i3 有两个核心，支持超线程技术 [S1]。首代 Core i3 于2010年年初推出 [S1]。

## 技术特性

Core i3 支持多种指令集架构，包括 x86、MMX、SSE、SSE2、SSE3、SSSE3、x86-64、SSE4、SSE4.2、AVX、AVX2、AVX-512、EM64T、SSE4.1、VT-X、AES、FMA3 等 [S1]。CPU 主频范围从 3.70 GHz 至 4.40 (OC) GHz [S1]。前端总线速率在 2.5 GT/s 至 8 GT/s 之间 [S1]。制作工艺覆盖 32nm 至 10nm [S1]。支持的 CPU 插座包括 Socket H (LGA 1156)、Socket H2 (LGA 1155)、Socket H3 (LGA 1150)、Socket H4 (LGA 1151)、Socket H5 (LGA 1200) 以及 LGA 1700 [S1]。核心代号涵盖 Clarkdale、Sandy Bridge、Ivy Bridge、Haswell、Haswell refresh、Skylake、Kaby Lake、Coffee Lake、Comet Lake、Ice Lake [S1]。

## 历代发展

第一代 Core i3 搭配 Intel H55 等芯片组（代号 IbexPeak），支持 Lynnfield 和 Havendale 处理器 [S1]。Havendale 只有两个处理器核心，但集成显示核心 [S1]。H55 采用单芯片设计，功能与传统南桥相似，使用传统的 DMI 技术连接 [S1]。接口方面，可以与其他5系列芯片组兼容 [S1]。

从第2代 Intel Core 开始，Core i3 多采用双核与超线程设计，但第8代、第9代的桌面电脑版 Core i3 为四核心设计 [S1]。第10代、第11代的桌面电脑版 Core i3 为四核心八线程设计 [S1]。

## 其他

Core i3 产品化时间为2010年至今，生产商为 Intel [S1]。相关条目包括 Intel Core 系列产品中的 Core i5、Core i7、Core i9 [S1]。
