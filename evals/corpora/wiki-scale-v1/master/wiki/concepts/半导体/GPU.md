# GPU

## 定义与概述

**图形处理器**（英语：Graphics Processing Unit，缩写：**GPU**），又称 **显示核心**（display core）、**视觉处理器**（video processor）、**显示晶片**（display chip）或 **图形晶片**（graphics chip），是一种专门在 个人电脑、 工作站、 游戏机 和一些 行动装置（如 平板电脑、 智慧型手机 等）上执行绘图运算工作的 微处理器。[S1] 以图形处理器为核心的 主板 扩展卡 也称 显示卡，或简称显卡。[S1]

图形处理器是 辉达 在1999年8月发表 GeForce 256 绘图处理晶片时首先提出的概念，在此之前，电脑中处理影像输出的显示晶片，通常很少被视为是一个独立的运算单元。[S1] 而对手 冶天科技（ATi）亦提出视觉处理器（Visual Processing Unit）概念。[S1] 图形处理器使 显示卡 减少对 中央处理器（CPU）的依赖，并分担部分原本是由中央处理器所担当的工作，尤其是在进行 三维 绘图运算时，功效更加明显。[S1] 图形处理器所采用的核心技术有 硬体座标转换与光源、立体环境 材质贴图 和 顶点 混合、 纹理压缩 和凹凸映射贴图、双重纹理四像素256位渲染引擎等。[S1]

## 历史

### 1970年代

ANTIC和CTIA晶片为Atari-8位元电脑提供硬体控制的 图形 和 文字 混合模式，以及其他视讯效果的支援。[S1] ANTIC晶片是一个特殊用途的处理器，用于映射 文字 和 图形 数据到视讯输出。[S1] ANTIC晶片的 设计师，Jay Miner随后为 Amiga 设计绘图晶片。[S1]

### 1980年代

Commodore Amiga是第一个于市场上包含映像显示功能在其视讯硬体上的电脑，而 IBM 8514 图形系统是第一个植入2D显示功能的PC显示卡。[S1] Amiga是独一无二的，因为它是一个完整的图形加速器，拥有几乎所有的影像产生功能，包括线段绘画，区域填充，块图像传输，以及拥有自己一套指令集（虽然原始）的辅助绘图处理器。[S1]

### 1990年代

1990年代初期， Microsoft Windows 的崛起引发人们对高性能、高解析度二维 点阵图 运算的兴趣。[S1] 1991年， S3 Graphics 推出第一款单晶片的2D图像加速器，名为S3 86C911。[S1] 到1995年，所有主要的PC绘图晶片制造商都于他们的晶片内增加2D加速的支援。[S1]

在1990年代初期和中期，中央处理器辅助的即时三维图像越来越常见于电脑和电视游戏上，从而导致大众对由硬体加速的3D图像要求增加。[S1] 早期于大众市场出现的3D图像硬体的例子有第五代视讯游戏机，如 PlayStation 和 任天堂64。[S1] 在电脑范畴，显著的失败首先尝试低成本的3D绘图晶片为 S3 ViRGE、 ATI 的 3D Rage，和 Matrox 的Mystique。[S1] 起初，高性能3D图像只可经设有3D加速功能（和完全缺乏2D GUI加速功能）的独立绘图处理卡上运算，如 3dfx 的Voodoo。[S1] Rendition的Verite是第一个能做到将影像、2D GUI加速和3D功能集成到一块晶片上的晶片组。[S1]

OpenGL 是出现于90年代初的专业图像 API，并成为在个人电脑领域上图像发展的主导力量。[S1] 随著时间的推移， DirectX 在90年代末开始受到Windows游戏开发商的欢迎。[S1] Direct3D 7.0支持硬体加速 座标转换和光源（T&L）。[S1] NVIDIA 的 GeForce 256（也称为NV10）是第一个在市场上有这种能力的显示卡。[S1]

### 2000年到现在

随著 OpenGL API和DirectX类似功能的出现，图形处理器新增可编程 着色 的能力。[S1] 辉达是首家能生产支援可编程著色晶片的公司，即 GeForce 3（代号为NV20）。[S1] 2002年10月，ATI发表了 Radeon 9700（代号为 R300），它是世界上首个Direct3D 9.0加速器。[S1]

随著绘图处理器的处理能力增加，他们的电力需求也增加。[S1] 高性能绘图处理器往往比目前的中央处理器消耗更多的电源。[S1]

2017年3月10日后由于适用于个人研究使用的GPU发布，近年来也逐渐受到许多研究者及公司的关注并广泛用于 深度学习。[S1]

## 绘图处理器公司

现时有许多公司生产绘图晶片。[S1] 以桌上型电脑与笔记型电脑为例，辉达和 超微 都是目前市场的领导者，分别拥有94%和6%的市场占有率。[S1] 手机、平板电脑等行动装置方面， 高通 等公司有较高市占率。[S1] 另外， 矽统科技 和 Matrox 等公司过去也曾生产图像晶片。[S1]

## 类型

### 独立显示卡

独立显示卡（Discrete Graphics Processing Unit，dGPU，简称独显）透过 PCI Express、 AGP 或 PCI 等扩展槽界面与主机板连接。[S1] 所谓的“独立(专用)”即是指独立显示卡内的 RAM 只会被该卡专用。[S1] 一些特别的技术，如辉达的 SLI、 NVLink 和AMD-ATI的 CrossFire 允许多个图形处理器共同处理影像资讯。[S1]

优点：相对集成显卡，独立显卡一般拥有更强劲的性能；消耗的系统资源更少；拥有例如 CUDA 一类的在部分领域可以起到辅助工作作用的处理单元。[S1] 缺点：购置计算机需要更多金钱；消耗的功率更多；体积更大；部分低端独立显卡性能可能不如核芯显卡。[S1]

### 整合式图形处理器

整合式图形处理器（Integrated Graphics Processing Unit，iGPU），是整合在主机板或CPU上的图形处理器，运作时会借用部分的系统记忆体。[S1] 2007年装设集成显示卡的 个人电脑 约占总出货量的90%[S1]。从前，集成图形处理器往往会被认为是不适合于执行3D游戏或精密的图形运算。[S1] 从2009年开始，整合GPU已经从主机板移至 CPU 了，如Intel从 Westmere微架构 开始将 Intel HD Graphics GPU整合到CPU至今，Intel将之称为 **处理器显示晶片**。[S1] AMD 也推出了整合GPU的 AMD APU、 AMD Athlon 和 AMD Ryzen with Radeon Graphics。[S1]

## 用于人工智能学习

人工智能 要用GPU的主要原因是因为GPU拥有强大的并行计算能力，适合处理大规模的 矩阵 运算和 向量 计算，而这些计算在人工智能算法中非常常见。[S1] 在传统的中央处理器（CPU）中，每个核心通常只能处理一个任务，因此在处理大量数据时速度会相对较慢。[S1] 而GPU拥有大量的计算单元（例如CUDA核心），可以同时执行许多相似的计算任务，因此能够在短时间内处理大量的数据。[S1] 这对于机器学习和深度学习等人工智能任务来说非常重要，因为它们通常涉及大量的矩阵运算和向量计算。[S1] 另外，人工智能算法中经常使用到 深度神经网络，这些网络拥有大量的参数需要进行训练。[S1] 传统的CPU在处理这些大规模神经网络时效率较低，而GPU能够通过并行计算加速神经网络的训练过程，从而大大缩短了训练时间。[S1]
