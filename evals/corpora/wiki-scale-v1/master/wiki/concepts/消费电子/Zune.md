# Zune

## 概述

Zune 是 微软 生产的 可携式媒体播放器，2006年11月发布 [S1]。该品牌覆盖所有媒体播放器和相关服务 [S1]。

## 硬件架构

Zune 采用东芝硬盘（与 iPod 相同），主控芯片为 Freescale i.MX31L 多媒体应用处理器（ARM1136 内核，90纳米制程，532MHz，128KB L2 Cache） [S1]。电源管理器为 Freescale MC13783（集成电源管理、USB OTG、模拟录音、数模转换、时钟、背光等） [S1]。影片转换器采用 Focus Enhancements FS456 [S1]。缓冲存储器采用三星 16MB [S1]。无线模块为 KEYSTREAM KS3021/KS7010，支持 IEEE 802.11g [S1]。立体声编解码器采用 Wolfson WM8978 [S1]。

## 固件与软件功能

Zune 操作系统基于适用于 ARM 架构的 Windows CE 内核，预装音乐和影片内容 [S1]。图形用户界面（GUI）包含音乐、影片、图片、社交、收音机、播客、市场、游戏和设置等部分，提供二维导航 [S1]。用户可通过方向键滚动，在音乐部分添加歌曲到快速播放列表，在照片部分自定义壁纸 [S1]。收音机部分支持北美、日本和欧洲的 FM 广播，并显示广播数据系统信息 [S1]。社交部分可广播用户资料和活动到附近设备 [S1]。

## 文件格式与数字版权管理

Zune 支持的音乐格式：Windows Media Audio、MP3、AAC [S1]。视频格式：Windows Media Video、MP4 [S1]。图片格式：JPEG [S1]。装置可播放使用 Windows Media DRM 录制的 WMA 和 WMV [S1]。Zune 使用 Windows Media DRM 数字版权管理系统，与 PlaysForSure 平台不兼容 [S1]。多媒体内容通过媒体传输协议（MTP）传输，其专有扩展 MTPZ 在 Zune 和基于 MTP 的软件之间建立互操作性屏障 [S1]。
