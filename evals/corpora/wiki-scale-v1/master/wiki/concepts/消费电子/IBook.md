# IBook

## 概述

iBook 是苹果公司旗下的一条笔记本电脑产品线，面向个人、家庭与教育市场，定位为廉价入门级产品[1]。初代产品 iBook G3 于1999年7月21日在纽约的 Macworld Conference & Expo 上发布，其设计受 iMac 影响，采用半透明彩色塑料外壳，口号为“iMac to go”[S1]。iBook 是第一款采用集成无线网络设计的主流计算机，其名称中的“i”代表互联网（Internet），强调与互联网的无缝集成[S1]。整个系列共历经三代产品，包括第一代蛤壳设计、第二代双 USB 设计以及末代 G4 处理器版本，在教育领域广受欢迎并取得商业成功[S1]。2005年苹果宣布向英特尔平台迁移，2006年发布 MacBook 系列取代 iBook，末代产品 iBook G4 于同年停产[S1]。

## 设计演变

### 第一代 iBook（1999-2001）

第一代 iBook 以独特的外观著称，拥有半透明彩色塑料外壳（如橘子、蓝莓、靛蓝等颜色），并在中心部位装有手提把手[S1]。苹果曾让高管提着 iBook 从高处跳下以展示外壳耐久性。该型号采用 PowerPC G3 处理器，配备 USB、Ethernet 和调制解调器接口，光驱为 CD-ROM[S1]。无线网络通过可选 AirPort 扩展卡实现，天线内置于显示面板边缘。第一代 iBook 因外形被戏称为“蛤壳”或“马桶座”，虽然稍有重量和规格争议，但销售成功[S1]。

### 第二代 iBook（2001-2003）

2001年5月1日，苹果推出第二代“双 USB”iBook，彻底重新设计，舍弃鲜艳色彩改用纯白轻薄外观，重量更轻，采用12英寸或14英寸 TFT 显示屏，分辨率提升至 1024x768[S1]。设计元素与 PowerBook G4 类似，白色塑料用于消费级产品，铝金属用于专业级。2003年10月22日，iBook G4 发布，处理器升级为 PowerPC G4，光驱改为吸入式，并采用 AirPort Extreme（802.11g）无线网卡[S1]。此后 iBook 外观基本保持不变。

## 型号与规格

以下为主要型号的规格摘要（所有信息均来自[S1]）：

- **iBook G3（1999年7月21日）**：12英寸 TFT（800x600），G3 300 MHz，32/64 MB 内存，6 GB 硬盘，CD-ROM，USB、Ethernet，AirPort（802.11b），Mac OS 8.6。 [S1]
- **iBook 第二版（2000年2月16日）**：G3 366 MHz，Mac OS 9.0.2，其他同初代。 [S1]
- **iBook Firewire/SE（2000年9月13日）**：G3 366/466 MHz，64 MB 内存，10 GB 硬盘，CD/DVD-ROM，增加 FireWire 和视频输出。 [S1]
- **iBook 双 USB（2001年5月1日）**：12英寸 TFT（1024x768），G3 500 MHz，128 MB 内存，10 GB 硬盘，CD/CDRW/DVD/Combo，Mac OS 9.1。 [S1]
- **iBook 14英寸（2002年1月7日）**：14英寸 TFT（1024x768），256 MB 内存，其他同后期双 USB。 [S1]
- **iBook G4（2003年10月22日）**：12英寸或14英寸 TFT（1024x768），G4 800/933/1000 MHz，256 MB 内存，30/40/60 GB 硬盘，吸入式 Combo 或 SuperDrive，AirPort Extreme（802.11g），Mac OS X 10.3。 [S1]
- **iBook G4 2005年中期（2005年7月26日）**：末代型号，G4 1.33/1.42 GHz，512 MB 内存（可扩至1.5 GB），40/60/80 GB 硬盘，ATI Mobility Radeon 9550 图形处理器（32 MB VRAM），Sudden Motion Sensor 防震感应，支持滚动的触控板，蓝牙 2.0+EDR，预装 Mac OS X 10.4 Tiger。 [S1]

## 扩展性与升级

iBook 允许用户自行安装内存和 AirPort 无线网卡，通过键盘上的两个卡榫即可移开键盘[S1]。但其他内部组件（如硬盘、光驱）的更换极为复杂，需要多种螺丝刀拆卸数十个螺丝，保固期内不允许用户自行操作[S1]。这一限制贯穿整个 iBook 系列。

## 市场与影响

iBook 以其独特的设计和无线网络能力吸引了消费者，在教育领域尤其受欢迎，取得了成功的销售业绩[S1]。2005年苹果宣布向英特尔平台迁移后，2006年推出 MacBook 系列，完全取代 iBook 产品线，末代 iBook G4 于2006年5月16日停产[S1]。
