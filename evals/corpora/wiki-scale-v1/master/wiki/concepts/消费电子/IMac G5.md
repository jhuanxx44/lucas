# IMac G5

## 概述

iMac G5是苹果公司于2004年8月31日推出的一体式桌面电脑，属于iMac系列中基于PowerPC芯片的第三代产品[S1]。该机型将电脑主机和电源集成在显示屏背面，厚度仅2英寸，是当时市场上最薄的台式机之一[S1]。iMac G5于2006年3月停产，随后被基于Intel Core Duo处理器的iMac取代[S1]。

## 设计特点

iMac G5采用铝制悬臂支撑，可调节屏幕角度，也可选配VESA挂载平板以适配标准支架[S1]。机身内部集成LCD屏幕（17英寸或20英寸宽屏）、处理器、硬盘和电源，外观简洁[S1]。整机重量较轻，设计延续了iMac系列“相框”风格[S1]。

## 硬件规格

- **处理器**：1.6 GHz或1.8 GHz PowerPC G5（PowerPC 970）64位处理器[S1]。
- **屏幕**：17英寸或20英寸宽屏LCD显示器[S1]。
- **硬盘**：Serial ATA接口（教育版型号为Parallel ATA），容量范围40GB至500GB[S1]。
- **显卡**：nVidia GeForce 5200绘图处理芯片（教育版使用更简单的GeForce MX4000）[S1]。
- **内存**：主板集成，标准配置随型号不同（2005年3月后标配512MB）[S1]。
- **接口**：USB 2.0、FireWire 400、10/100Base-T以太网、V.92调制解调器、视频输出、模拟音频输入、结合模拟/mini-TOSLINK音频输出[S1]。
- **操作系统**：预装Mac OS X 10.3 Panther，支持升级至10.4 Tiger[S1]。

## 型号与更新

iMac G5共有三种零售型号，另有一种教育版（无光驱、无调制解调器、使用GeForce MX4000显卡）[S1]。

### 2005年3月更新
- 入门型号处理器提升至1.8 GHz，最高型号达到2.0 GHz[S1]。
- 标准内存增至512MB[S1]。
- 可选购双面8x SuperDrive光驱[S1]。
- 所有型号标配AirPort Extreme无线网络、蓝牙2.0和ATI Radeon 9600显卡（128MB显存）[S1]。
- 随附iLife '05和Mac OS X 10.4 Tiger[S1]。

### iMac G5 (iSight) 版本
- 这是第三次改版（Rev.C），也是最后一代采用PowerPC处理器的iMac[S1]。
- 新增内置iSight摄像头和遥控器，支持Frontrow媒体中心功能[S1]。

## 问题与召回

2005年8月18日，苹果启动“iMac G5视频与电源问题维修扩展计划”[S1]。受影响机型为2004年9月至2005年6月售出的17英寸和20英寸型号（1.6 GHz或1.8 GHz处理器），可能出现视频画面杂乱、无视频或无电源故障[S1]。序列号前五位在以下范围内的设备可能受影响：W8435-W8522、QP435-QP522、CK435-CK522、YD435-YD522[S1]。

## 停产与后续

iMac G5于2006年3月停产，随后苹果于2006年1月推出基于Intel Core Duo处理器的iMac（即iMac Core Duo），标志iMac全面转向x86架构[S1]。
