# Wayback Machine

## 概述

**网站时光机**（Wayback Machine）是万维网的数码档案馆，由非营利组织互联网档案馆创建并持有，是其最重要的服务之一。它允许用户“回到过去”，查看过往网站的样子。创始人布鲁斯特·卡利（Brewster Kahle）和Bruce Gilliat于2001年公开推出该服务，旨在解决网站在维护或关闭时无法查看内容的问题，同时提供网页历史存档版本，以实现“普及所有知识”。[S1]

名称源自动画片《The Rocky and Bullwinkle Show》中的“WABAC机器”（发音为Way-back），这是一个时间旅行装置。[S1]

## 历史与发展

网站时光机于1996年开始存档缓存网页，目标是在五年后公之于众。从1996年到2001年，数据保存在数字磁带上，Kahle偶尔允许研究人员和科学家使用数据库。2001年，互联网档案馆成立五周年时，加州大学伯克利分校举行了网站时光机的公布仪式。推出时，它已存档超过100亿个页面。[S1]

如今，数据存储在互联网档案馆的大型Linux节点群集上。有时会重新访问并存档网站的新版本。用户也可通过搜索框手动捕获网站（若网站允许爬虫索引）。[S1]

2024年9月至10月间，时光机遭到攻击，资料外泄。2024年10月9日，遭遇阻断服务攻击。2024年10月14日恢复运作，但存档功能停摆至11月6日。[S1]

## 技术细节

网站时光机开发了软件用于爬虫索引并下载所有可公开访问的万维网页面、Gopher层次结构、Usenet公告板系统和可下载软件。所收集信息不包括互联网上所有可用信息，因许多数据受发布者限制或存储在不可访问的数据库中。为克服缓存网站的不一致性，2005年互联网档案馆开发了Archive-It.org，使机构和内容创作者可自愿收集和保存数字内容并创建数字档案馆。[S1]

爬虫索引来自多种来源，部分从第三方导入，部分由存档内部生成。自2010年以来，“Worldwide Web Crawls”一直在运行并捕获全球网站。快照捕获频率因网站而异，Worldwide Web Crawls中的网站每次爬网存档一次，爬网可能耗时数月甚至数年。一次可能有多个爬网同时进行，一个站点可能包含在多个爬网列表中，因此爬网频率差异很大。[S1]

### 存储容量增长

2003年，每月增长12 TB。2004年6月首个100 TB机架投入使用。2009年迁移到Sun开放式存储和Sun模块化数据中心，包含约3 PB数据，每月增长100 TB。截至2014年12月，存有4350亿个网页和近9 PB数据，每周增长约20 TB。2016年7月约15 PB，2018年9月超过25 PB。截至2024年1月3日，已存档超过8600亿个网页和超过99 PB的数据。[S1]

### 成长数据

下表显示已存档页面数（亿）：2005年400，2008年850，2012年1500，2013年3730，2014年4000，2015年4520，2016年4590，2017年2790，2018年3100，2019年3450，2020年4050，2021年5140，2022年6400，2024年8660。[S1]

### 网站排除方针

网站时光机尊重机器人排除标准（robots.txt）以决定网站是否受爬网或存档是否可公开查看。网站所有者可通过robots.txt选择退出，以前存档的页面也会立即不可用。有时网站所有者直接联系要求停止爬网或存档，互联网档案馆会遵守。[S1]

2017年4月，有报道称一些已倒闭网站因使用robots.txt排除搜索引擎而无意中被时光机排除。网站排除方针基于2002年加州大学伯克利分校的建议，以规避诉讼风险。2017年开始放宽方针，停止遵循robots.txt对美国政府和军方网站进行爬网和显示，随后更广泛地忽略robots.txt。[S1]

## 用途

自2001年公开发布以来，学者们广泛研究其存储和收集方式。截至2013年，约有350篇文章涉及，主要来自信息技术、图书馆学和社会科学领域。社会科学学者使用它分析网站发展对公司成长的影响。网站时光机存档页面时通常包含大多数超链接，使其保持活动状态。印度研究人员研究其保存在线学术出版物中超链接的能力，发现保存了略多于一半的超链接。[S1]

记者使用网站时光机查看失效网站、过时新闻报道及被更改的网站内容，用于追究政治家责任、揭穿谎言。例如，2014年乌克兰东部叛军领导人伊戈尔·斯特列尔科夫的社交媒体存档页面显示其吹嘘击落飞机，后该文被删；2017年Reddit讨论中提及白宫网站删除气候变化内容，引发了“为科学游行”。[S1]

### 局限

2014年，从抓取到可查看存在6个月延迟；目前延迟为3-10小时。网站时光机仅提供有限搜索功能，“站点搜索”允许根据描述词汇查找站点，而非网页词汇。由于爬虫限制，无法完全存档互动式网页（如Flash、JavaScript、渐进式网络应用程序），难以提取非HTML内容，导致超链接损坏和图像丢失；无法存档不包含链接的“孤立页面”。爬虫根据预设深度限制追踪有限超链接。[S1]

## 法律证据

### Netbula LLC v. Chordiant Software Inc. (2009)

被告Chordiant要求Netbula禁用其网站的robots.txt文件，因该文件导致时光机追溯性撤销对先前版本存档的访问，Chordiant认为其中含有利诉讼材料。Netbula反对，但互联网档案馆雇员宣誓声明无法通过其他方式访问网页。地区法院法官霍华德·劳埃德（Howard Lloyd）驳回Netbula论点，命令其暂时禁用robots.txt以允许Chordiant检索存档页面。[S1]

### Telewizja Polska USA, Inc. v. Echostar Satellite (2004)

诉讼当事人试图使用网站时光机档案作为有效证据来源，可能属首次。EchoStar表示将提供波兰电视台网站过去内容的快照作为证据。[S1]
