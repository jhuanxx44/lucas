# 升阳电脑

## 公司概览

升阳电脑（Sun Microsystems），又称太阳计算机系统、太阳微系统，是一家已不存在的计算机系统与软件公司，创建于1982年2月24日，1986年在美国纳斯达克上市，后于2009年被甲骨文公司收购，结束长达27年的公司历史。[S1] 公司名称“Sun”来源于斯坦福大学网络（Stanford University Network）的缩写。[S1] 公司总部位于美国加利福尼亚州圣克拉拉。[S1] 升阳电脑的主要产品包括服务器、工作站、数据存储设备和服务，产业涉及计算机系统和软件。[S1] 2009年，公司员工人数为29,000人，营业额约114.49亿美元。[S1]

## 历史沿革

1982年2月24日，斯坦福大学研究生维诺德·科斯拉、安迪·贝托尔斯海姆和史考特·麦克里尼创立了太阳计算机系统。不久后，伯克利软件套件（BSD）的主要开发者比尔·乔伊加入公司，被视为最初的创始人之一。[S1] 公司从1982年7月的第一季度开始盈利。[S1] 1992年，升阳推出了市场上第一台多处理器工作站，并于次年进入财富500强。[S1] 1995年，升阳开发了Java技术，这是第一个通用软件平台。[S1] 1997年，升阳开始推出其新的64位服务器家族。[S1] 2009年4月20日，甲骨文公司宣布以每股9.50美元，总计74亿美元收购太阳计算机系统公司。[S1]

升阳曾在行业中被认为是最具创造性的企业之一，尝试新的软件方式和定价模式。[S1] 它是极少数几个自己生产微处理器、电脑系统以及操作系统的公司之一。[S1] 1995年以来，市场成长迅速。[S1]

## 产品与技术

### 硬件产品

升阳设计制造基于CMT技术的UltraSPARC T1、UltraSPARC T2和Rock微处理器。[S1] 硬件产品包括基于SPARC的系统（如SPARCstation）和基于x86的系统。[S1] 除设计制造基于SPARC处理器的设备外，也与英特尔和超威半导体合作生产服务器。[S1]

### 软件产品

升阳的主要操作系统为Solaris，具有32位和64位两个版本，并同时支持SPARC系列和x86系列处理器。[S1] 其操作系统也采用开放源代码，称为OpenSolaris项目。[S1] 升阳开发了Java平台，包括Java、GlassFish（Sun Java System Application Server）等。[S1] 其他软件包括办公套件StarOffice、数据库管理系统MySQL和Java DB、NetBeans、Sun Grid Engine、Sun Studio、Sun Identity Manager、Sun Virtual Box、HotJava等。[S1]

## 收购与结局

2009年4月20日，甲骨文公司宣布以每股9.50美元，总计74亿美元收购太阳计算机系统公司。[S1] 2010年1月27日，收购完成，升阳电脑正式结束运营。[S1] 甲骨文公司在其硬件产品上使用甲骨文与升阳结合的标志。[S1]
